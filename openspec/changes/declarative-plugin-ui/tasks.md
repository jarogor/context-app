# Задачи

Изменение зонтичное и реализуется поэтапно: **Фаза A (сейчас)** убирает
автономные frontend-плагины и переносит их UI в приложение; **Фаза B (отложено)**
вводит декларативный протокол и SDK для сторонних плагинов. До завершения фазы B
изменение не архивируется. Модель декларативного UI (спека `plugin-ui`) и
отсутствие `kind: "ui"` фиксируются сразу — они описывают целевое состояние.

## Фаза A. Отказ от автономных frontend-плагинов (сейчас)

- [x] 1.1 Перенести UI уведомлений (`plugins/notifications-ui`) в приложение как встроенную поверхность `src/lib/NotificationsPanel.svelte`; обновить `openspec/specs/notifications` и тесты
- [x] 1.2 Перенести UI настроек (`plugins/settings-ui`) в приложение (`src/lib/SettingsPage.svelte`); обновить `openspec/specs/settings` и тесты
- [x] 1.3 Перенести UI стора плагинов (`plugins/plugin-store-ui`) в приложение (`src/lib/StorePage.svelte`); обновить `openspec/specs/plugin-store` и тесты

## Фаза B. Декларативный UI и SDK (отложено)

> Начинается после стабилизации фазы A. Контракт описывает целевое состояние
> (спека `plugin-ui`), но реализация протокола и SDK — отдельный заход.

- [ ] B1.1 Зафиксировать в `packages/ui-schema` схему декларативного UI: версия, узлы, пространства, событие → идентификатор действия; покрыть типами и проверить `npm run check`
- [ ] B1.2 Определить и описать первый набор пространств интерфейса и минимальный набор разрешённых компонентов и свойств; подтвердить `openspec validate declarative-plugin-ui`
- [ ] B2.1 Ввести хост-команды для интентов: приём действия `{space, action, values}` и возврат обновлённой декларации; обновить `packages/testing` фикстуры
- [ ] B2.2 Реализовать рендерер `ui-schema` в оболочке: узлы → компоненты и токены `@texture/ui`, обработка неизвестных узлов; компонентные тесты
- [ ] B2.3 Реализовать реестр пространств и каталог разрешённых элементов/свойств с диагностикой недопустимого вклада; тесты
- [ ] B3.1 Ввести SDK для UI-плагинов (Rust PDK) с типизированными компонентами, пространствами и действиями; пример-плагин и тесты
