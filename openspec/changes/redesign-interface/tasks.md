# Задачи: redesign-interface

Пять этапов (см. `design.md`, D11). Каждый этап оставляет приложение рабочим.
Проверка по умолчанию — `make verify`; где полезнее точечная проверка, она
указана в задаче. Браузерные снимки Playwright обновляются осознанно, глазами.
