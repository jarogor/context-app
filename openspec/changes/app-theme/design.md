## Context

См. `proposal.md` — Why. Оформление уже сведено к токенам `@texture/ui`
(`packages/ui/src/tokens.css`) и применяется ко всем поверхностям, включая
декларации плагинов. Сейчас существует один набор токенов, а `:root` фиксирует
`color-scheme: light`. Значения настроек приложения хранит базовый плагин
настроек (`settings.store@1`), собственную секцию приложения объявляет ядро в
`src-tauri/src/plugin/app_host.rs` (`APP_SETTINGS_SCHEMA`), читает значения через
`invoke_capability`. Все команды ядра, обращающиеся к общему `Mutex<AppState>`,
должны быть `async` (правило из `AGENTS.md`).

Ограничения:
- Компоненты дизайн-системы не должны содержать литералов оформления — только
  токены; переключение темы не должно менять их код.
- Интерфейс плагинов строится тем же рендерером и теми же токенами.
- Всё, что требует загрузки, читается на бутстрапе, до первого кадра.

## Goals / Non-Goals

**Goals:**
- Два набора токенов (светлый и тёмный) и предпочтение темы `light`/`dark`/`system`.
- Применение темы к документу до первого кадра и немедленно при изменении.
- Значение темы живёт в собственной секции настроек приложения и переживает
  перезапуск.

**Non-Goals:**
- Оформление содержимого читалки (EPUB/PDF) и обложек: они сохраняют
  собственные цвета и не переключаются темой интерфейса.
- Пользовательские темы, темы из плагинов, редактор палитры.
- Серверная/сетевая синхронизация настроек темы.

## Decisions

### Атрибут темы на корне документа

Активная тема задаётся атрибутом `data-theme="light|dark"` на
`document.documentElement`, а `system` разрешается в конкретное значение перед
установкой. `:root` остаётся светлым набором по умолчанию, тёмный набор
добавляется селектором `:root[data-theme='dark']`, `color-scheme` следует теме.

Альтернатива — чистый CSS через `@media (prefers-color-scheme: dark)`: не
позволяет отличить явную `dark` от `system` и заставляет дублировать селекторы.
Разрешение в JS даёт один источник и единообразный тест.

### Модуль темы в дизайн-системе

Пакет `@texture/ui` владеет и токенами, и логикой темы: новый
`packages/ui/src/theme.ts` экспортирует тип предпочтения, чистую функцию
`resolveTheme(preference, prefersDark)` и применение
`applyTheme(preference, root?, media?)`. Оболочка вызывает его; компоненты о
теме не знают. Это сохраняет принцип «тема — шов оформления», где владелец шва —
дизайн-система.

### Тема применяется на бутстрапе и сразу при изменении

`src/main.ts` до монтирования оболочки применяет `system` — экран загрузки
соответствует теме ОС. `loadBootstrap` параллельно читает предпочтение из
настроек и применяет его; при ошибке остаётся `system`. Изменение отслеживается
через уже существующее событие `settings:changed`: оболочка читает из payload
секцию `app.general` и значение `appearance.theme` и применяет тему без запроса
к ядру.

### Чтение значения ядром

`app_host.rs` получает поле-выбор `appearance.theme` (значения `light`, `dark`,
`system`, по умолчанию `system`) и вспомогательную функцию чтения строки по
аналогии с `app_setting_bool`. Новая `async` Tauri-команда `theme_preference`
возвращает сохранённое значение (с приведением неизвестного к `system`).
Команда читает настройку через runtime базовых плагинов, а не через прямой
доступ к файлу, чтобы не дублировать модель хранения.

## Risks / Trade-offs

- **Вспышка светлой темы до применения сохранённой** → применить систему до
  монтирования, а сохранённое значение — в бутстрапе, до `phase = 'ready'`.
- **Тёмные значения токенов подобраны на глаз и могут требовать доводки** →
  палитру задать по аналогии со светлой, проверить контраст в браузерном тесте;
  правка значений не затрагивает код компонентов.
- **Содержимое читалки остаётся светлым в тёмной теме** → осознанное
  ограничение: текст книги и обложки — не интерфейс; вынесено в Non-Goals.
- **`settings:changed` приходит и от других секций** → фильтровать по
  `app.general`, иначе оболочка будет зря трогать тему.

## Open Questions

- Точные значения тёмной палитры (фон, поверхности, границы) — уточняются
  визуально в ходе реализации; на контракт и задачи не влияют.
