## MODIFIED Requirements

### Requirement: Открытие директории с книгами как библиотеки

Приложение SHALL распознавать директорию с книгами через поставляемый source-плагин `library` (действие `probe`) и открывать её как внешнюю библиотеку в режиме `external` с именем источника; при этом файлы и папки внешней библиотеки SHALL оставаться без изменений.

#### Scenario: Открытие существующей директории с книгами

- **WHEN** пользователь указывает путь к директории с книгами при открытии
- **THEN** приложение распознаёт её через source-плагин `library`, открывает её в режиме `external` с именем источника, строит виртуальный каталог и позволяет работать с книгами без изменения файлов библиотеки

#### Scenario: Открытие пустой директории

- **WHEN** пользователь указывает путь к несуществующей или пустой директории
- **THEN** приложение создаёт собственную портируемую структуру библиотеки

#### Scenario: Открытие портируемой библиотеки

- **WHEN** пользователь указывает путь к портируемой библиотеке
- **THEN** приложение открывает её в собственном формате без признаков внешнего режима

### Requirement: Read-only доступ к внешней библиотеке

Каталог внешней библиотеки SHALL быть доступен только для чтения: приложение SHALL not изменять и не удалять файлы библиотеки и не создавать в ней новых файлов. Чтение структуры и метаданных библиотеки SHALL выполняться через host-functions source-плагина, ограниченные песочницей внутри корня.

#### Scenario: Импорт книги в внешнюю библиотеку отклоняется

- **WHEN** пользователь пытается импортировать книгу в открытую внешнюю библиотеку
- **THEN** операция отклоняется с понятным сообщением об ошибке, и ни один файл библиотеки не изменяется

### Requirement: Виртуальный каталог внешней библиотеки

Приложение SHALL строить виртуальный каталог книг внешней библиотеки из данных, полученных от source-плагина `library`: полного сканирования (`scan`), сохранённого согласованного индекса или частичного пересканирования изменённых папок (`scan_book`). Каталог SHALL содержать для каждой книги название, авторов, файлы содержимого и путь к обложке. Структура каталога (название, авторы, серии, теги, файлы) SHALL соответствовать собственному формату приложения.

#### Scenario: Книга с метаданными

- **WHEN** source-плагин `library` возвращает книгу с файлом содержимого и обложкой
- **THEN** виртуальный каталог содержит запись книги с названием, авторами, файлом содержимого и обложкой

#### Scenario: Книга без обложки

- **WHEN** в папке книги отсутствует файл обложки
- **THEN** книга присутствует в каталоге без обложки

#### Scenario: Повторное открытие без изменений

- **WHEN** приложение повторно открывает библиотеку, для которой существует актуальный локальный индекс и не обнаружены изменения
- **THEN** каталог восстанавливается из индекса без полного сканирования всех книг

#### Scenario: Новая книга после предыдущего открытия

- **WHEN** после предыдущего открытия в библиотеке появилась новая книга
- **THEN** каталог дополняется новой книгой после инкрементальной синхронизации или проверки при открытии

#### Scenario: Повторное сканирование при запуске

- **WHEN** приложение запускается повторно с той же библиотекой, в которой появились новые книги или папки, а индекс отсутствует, повреждён или признан несовместимым
- **THEN** виртуальный каталог строится заново через полное сканирование source-плагином и отражает текущее содержимое библиотеки
