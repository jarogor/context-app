## ADDED Requirements

### Requirement: Метаданные файлов в перечислении директории

Host-функция `fs_list_dir` SHALL возвращать для каждой записи имя и тип
(`file`, `dir`, `symlink` — без следования по ссылке), а для файловых записей —
дополнительно размер в байтах и время последнего изменения в миллисекундах Unix.
Метаданные SHALL получаться без чтения содержимого файла, чтобы плагин мог
обнаруживать изменения без повторного чтения. При недоступности метаданных
соответствующие поля SHALL быть `null`, а не ошибочным значением.

#### Scenario: Файловая запись с метаданными

- **WHEN** плагин перечисляет директорию, содержащую файл
- **THEN** запись файла содержит размер и время последнего изменения, полученные без чтения содержимого

#### Scenario: Отсутствующие метаданные

- **WHEN** размер или время изменения файла недоступны
- **THEN** соответствующее поле записи равно `null`, а перечисление не завершается ошибкой

#### Scenario: Каталоги и ссылки без метаданных файла

- **WHEN** запись является каталогом или символической ссылкой
- **THEN** запись содержит имя и тип без размера и времени изменения файла
