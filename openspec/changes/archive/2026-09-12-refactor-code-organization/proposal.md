## Why

Код-база выросла: модели, тесты и логика команд находятся вперемешку с реализацией модулей, а константы разбросаны по файлам. Уже добавлены `.editorconfig` и базовое форматирование (коммиты `1b3ebf2`, `b68df43`, `9181c5a`), но единообразной структуры файлов и согласованного стиля пока нет (расхождение: `.editorconfig` задаёт для `*.rs` табуляцию, а rustfmt по умолчанию форматирует пробелами).

## What Changes

- Вынос тестов из файлов реализации: инлайн-блоки `#[cfg(test)] mod tests` переносятся в отдельные файлы тестов рядом с модулями (например, `src-tauri/src/library/tests.rs`), из модуля подключаются через `#[cfg(test)] mod tests;`. Внешнее поведение и публичные API не меняются.
- Вынос моделей в отдельные файлы: инлайн-структуры и перечисления (`BookContent`, `Layout`, `WrittenFiles`, `FileConfig`/`DataConfig`, `HostSink`/`LoadedPlugin`/`PluginRuntime`/`PluginManifest`) переносятся в собственные файлы рядом с модулями по уже принятому в `catalog/entities/` паттерну.
- Вынос логики команд: `src-tauri/src/commands.rs` становится компактным перечнем команд; реализация каждой команды (`import_book`, `list_books`, `get_cover`, `get_book_content`) выносится в отдельный обработчик. Имена команд и их сигнатуры не меняются — фронтенд не затрагивается.
- Вынос констант: общие константы (имена файлов и папок библиотеки, имя конфигурационного файла, имя переменной окружения, имя demo-плагина) централизуются в отдельный модуль `constants.rs`. Константы, несущие доменную нагрузку локально (например, версия контракта плагинов), остаются в своих модулях.
- Настройки стиля и повторное форматирование: добавляется `rustfmt.toml` с настройками стиля, согласованными с `.editorconfig` (устранение расхождения по отступам), выполняется повторный `cargo fmt --all`, появляется однотипный npm-скрипт проверки/форматирования для фронтенда.
- Проверка после рефакторинга: `cargo test`, `cargo clippy -- -D warnings`, `npm run check` — без регрессий.

## Capabilities

Рефакторинг не меняет внешнее поведение приложения: команды, схема БД, структура портируемой библиотеки и плагинный контракт остаются прежними. Поэтому change объявлен с `skip_specs: true` (изменение только структуры и стиля кода, спецификационных требований не вводится и не меняется).

## Impact

- `src-tauri/src/lib.rs`, `src-tauri/src/commands.rs` — реорганизация модулей и вынос логики команд.
- `src-tauri/src/{catalog,library,import,reading,plugin,config}/*` — вынос тестов, моделей и общего кода в отдельные файлы.
- Новый модуль `src-tauri/src/constants.rs` и файл `src-tauri/rustfmt.toml`; дополнение скриптов в `package.json`.
- Без изменений: фронтенд (Tauri IPC-команды и их сигнатуры), схема БД, структура портируемой библиотеки, контракт плагинов.
- Проверки: `cargo test`, `cargo clippy -- -D warnings`, `npm run check` (svelte-check + tsc), `npm run format:ts`.
