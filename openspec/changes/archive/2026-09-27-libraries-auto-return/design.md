## Context

Раздел «Библиотеки» — состояние оболочки (`librariesOpen`), а страница списка
книг — основной раздел с frontend-плагином библиотеки. Открытие библиотеки
выполняется на странице «Библиотеки» командой `select_source_library`, которая
возвращает управление после завершения открытия/индексации.

## Goals / Non-Goals

**Goals:**

- После успешного открытия библиотеки сразу показывать книги.

**Non-Goals:**

- Менять модель хранения состояния оболочки или список книг.

## Decisions

### D1. Возврат через колбэк из страницы

Оболочка передаёт в `LibrariesPage` колбэк `onOpened`. Страница вызывает его после
успешного завершения `select_source_library` (открытие и индексация уже
завершены), и оболочка закрывает страницу «Библиотеки» (`librariesOpen = false`).
При ошибке колбэк не вызывается — пользователь остаётся на странице и видит
ошибку. Альтернатива «слушать `source-catalog-changed` в оболочке» избыточна:
страница уже знает момент успеха.

## Risks / Trade-offs

- [Список книг может ещё догружаться после возврата] → `library-ui` показывает
  состояние загрузки; событие `source-catalog-changed` уже приводит к загрузке книг.
