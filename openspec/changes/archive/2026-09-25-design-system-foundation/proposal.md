## Why

Интерфейс собран кастомно и продублирован по пяти независимым Vite-приложениям
(оболочка + четыре frontend-плагина): нет общей дизайн-системы, нет общих токенов,
нет ни одного UI-теста. Это делает оформление несогласованным и заставляет
проверять интерфейс глазами. Прежде чем менять модель плагинов на декларативный
UI, нужен общий фронтенд-фундамент: единая дизайн-система, шов для тем и
воспроизводимый тестовый стенд.

## What Changes

- Ввести **npm workspaces**: корень + `plugins/*` + `packages/*`, один lock и
  единые версии зависимостей.
- Завести пакет **`packages/ui`** — дизайн-система на shadcn-svelte
  (Bits UI + Tailwind v4) с **токенами оформления** (CSS-переменные) как единым
  швом для будущих тем.
- Завести пакет **`packages/ui-schema`** — скелет словаря UI и его типов (задел
  под декларативный UI плагинов); рендер и протокол пока не реализуются.
- Перевести оболочку и все frontend-плагины на общие компоненты и токены,
  убрать ad-hoc стили.
- Ввести **тестовый стенд**: Vitest + `@testing-library/svelte` для компонентов
  с мок-мостом Tauri, Playwright для браузерных сквозных сценариев (оболочка и
  iframe-плагины) с мок-мостом вместо Tauri.
- Адаптировать скрипты сборки frontend-плагинов под workspaces.

## Capabilities

### New Capabilities

- `design-system`: общая библиотека компонентов и токенов для оболочки и всех
  frontend-плагинов, токены как шов для тем и воспроизводимая проверка UI.

### Modified Capabilities

_Нет: поведение областей не меняется, меняется их оформление и способ
проверки._

## Impact

- Новые пакеты: `packages/ui`, `packages/ui-schema`.
- Реструктуризация: корневой `package.json` (workspaces), `plugins/*/package.json`,
  общие конфиги Tailwind/TypeScript.
- Frontend: `src/App.svelte`, `src/lib/PluginFrame.svelte` и компоненты всех
  frontend-плагинов (`library-ui`, `notifications-ui`, `settings-ui`,
  `plugin-store-ui`) переводятся на дизайн-систему.
- Сборка: `scripts/build-frontend-plugins.sh`, конфиги Vite/TypeScript.
- Тесты: новые конфиги Vitest и Playwright, мок моста Tauri.
- Rust-ядро, WASM-плагины и контракты плагинов **не затрагиваются**.
