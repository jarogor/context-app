## MODIFIED Requirements

### Requirement: Глобальный поиск по заметкам

Реестр SHALL предоставлять **единый поиск** по всем наборам и заметкам. Поиск SHALL
учитывать имя набора, отображаемое имя книги, название и комментарий заметки, её
цитату и текст, а также место. При непустом запросе реестр SHALL показывать только
подходящие записи; при пустом запросе — весь реестр. Пустой результат поиска SHALL
показываться информативно. Поле поиска SHALL быть **общим компонентом поиска**
дизайн-системы, единым с другими страницами-списками.

#### Scenario: Поиск по содержимому заметок

- **WHEN** пользователь вводит запрос, совпадающий с цитатой или текстом заметки
- **THEN** реестр показывает наборы с такими заметками

#### Scenario: Поиск по имени набора и книги

- **WHEN** пользователь вводит запрос, совпадающий с именем набора или отображаемым именем книги
- **THEN** реестр показывает соответствующие наборы

#### Scenario: Поиск без результатов

- **WHEN** запрос не совпадает ни с одним набором или заметкой
- **THEN** реестр показывает информативное сообщение об отсутствии результатов

#### Scenario: Поиск единообразен с другими областями

- **WHEN** отображается реестр заметок
- **THEN** поиск выполнен тем же общим компонентом поиска, что и на других страницах-списках

### Requirement: Реестр наборов заметок по всем книгам

Приложение SHALL предоставлять реестр **всех** наборов заметок по всем книгам,
полученный из хранилища заметок одним агрегатным запросом, без опроса книг по
отдельности. Реестр SHALL показывать наборы, **сгруппированные по книге** (наборы
одной книги идут подряд), и для каждой записи — имя набора, отображаемое имя книги
и число заметок. **Заметки — первичны, книга — подпись:** имя набора SHALL быть
основным акцентом записи, а имя книги — компактным контекстом рядом, а не
отдельным заголовком. Реестр SHALL показывать информативное пустое состояние,
когда наборов нет. Просмотр реестра SHALL NOT изменять наборы и заметки. Реестр
SHALL быть собран из **общего каркаса страницы-списка**; пункт набора SHALL быть
оформлен **единым видом пункта** (имя набора акцентом; под ним метаинформация —
дата изменения, а при её отсутствии дата создания, первой, затем книга; число
заметок — справа от имени; действия в контекстном меню); вёрстка SHALL быть
**адаптивной**: на широком окне поиск — колонкой слева, список — справа, при этом
список SHALL оставаться вертикальным списком.

#### Scenario: Наборы всех книг в одном реестре

- **WHEN** у нескольких книг есть наборы заметок
- **THEN** реестр показывает наборы всех этих книг, сгруппированные по книге

#### Scenario: Состав записи реестра

- **WHEN** реестр показывает набор
- **THEN** запись содержит имя набора (основной акцент), отображаемое имя книги (подпись) и число заметок

#### Scenario: Книга не заслоняет заметки

- **WHEN** реестр показывает набор
- **THEN** имя набора показано заметнее имени книги, а имя книги — как подпись-контекст

#### Scenario: Пустой реестр

- **WHEN** ни у одной книги нет наборов заметок
- **THEN** реестр показывает информативное пустое состояние

#### Scenario: Просмотр не меняет данные

- **WHEN** пользователь просматривает реестр
- **THEN** наборы и заметки остаются без изменений

#### Scenario: Единый каркас и адаптивность реестра

- **WHEN** открыт раздел «Заметки»
- **THEN** реестр использует общий каркас страницы-списка; на широком окне поиск расположен колонкой слева, а список — справа и остаётся вертикальным списком

#### Scenario: Пункт набора показывает метаинформацию и действия

- **WHEN** реестр показывает набор
- **THEN** имя набора показано сверху, число заметок — справа от имени, под именем — дата (изменения, а при её отсутствии создания) и книга, а действия доступны из контекстного меню в конце строки
