# bootstrap-project

## Why

Нужен каркас десктопной + мобильной «личной библиотеки»: приложения для хранения и чтения книг с переносимой файловой базой (директория, которую можно скопировать на флешку и перенести на другое устройство) и расширяемостью через изолированные WASM-плагины. Без этого каркаса невозможно запускать дальнейшие итерации (мобильные сборки, сетевые плагины, а востребованные форматы и синхронизацию).

## What Changes

- Инициализация проекта Tauri 2 + Svelte (Rust-ядро + системный WebView), сборка и запуск на десктопе.
- Определение структуры портируемой директории библиотеки: файл SQLite, папки для файлов книг, обложек и плагинов.
- Схема БД базовых сущностей: книга, автор, серия, тег, файл.
- Импорт книги в формате EPUB с извлечением базовых метаданных (title, авторы, обложка).
- UI: список книг + простейшая read-view.
- Скелет плагинной подсистемы: контракт extension point(ов) на Rust-стороне, интеграция Extism host runtime, загрузка одного demo-плагина (`.wasm`) из локальной папки `plugins/`.

Явно НЕ входит в этот change: мобильные сборки, установка плагинов по сети, управление плагинами из UI, поддержка других форматов книг, синхронизация.

## Capabilities

### New Capabilities

- `library-storage`: портируемая структура директории библиотеки, схема SQLite-БД для книг, авторов, серий, тегов и файлов.
- `book-import`: импорт книги в формате EPUB в библиотеку с извлечением базовых метаданных.
- `library-ui`: отображение списка книг и открытие книги в простейшей read-view.
- `plugin-system`: контракт extension point(ов) и загрузка WASM-плагинов через Extism host runtime из локальной папки `plugins/`.

## Impact

- Создание нового Rust-проекта на базе Tauri 2 (`generate` / `cargo`), структура `src-tauri/` и Svelte-фронтенда.
- Зависимости: `tauri` 2.x, `rusqlite`, `extism`, EPUB-парсер (например `epub`/`zip`), Svelte 5.
- Новая портируемая структура директории библиотеки — контракт для всех последующих and changes.
- Демонстрационный WASM-плагин как опорный артефакт для плагинной подсистемы.
