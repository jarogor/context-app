## MODIFIED Requirements

### Requirement: UI настроек

Система SHALL предоставлять UI настроек отдельным frontend-плагином: страница со списком секций отображается в контентной области раздела настроек при выбранном пункте меню «Настройки», а точка входа в раздел — кнопка-иконка настроек в верхней панели каркаса. Для каждого поля секции UI SHALL отображать человекочитаемое название и типизированный контрол: флажок для `boolean`, текстовое поле для `string`, числовое поле для `number`, выбор для `select` и текстовое поле JSON для `json`. Дискретные контролы (`boolean`, `select`) SHALL сохранять значения секции непосредственно при изменении. Оболочка SHALL предоставлять верхнюю панель, меню настроек и контентную область и SHALL not содержать кода секций настроек.

#### Scenario: Кнопка открывает страницу настроек

- **WHEN** пользователь нажимает кнопку-иконку настроек в верхней панели
- **THEN** в контентной области раздела настроек отображается страница настроек со списком секций

#### Scenario: Возврат с главной страницы

- **WHEN** пользователь закрывает раздел настроек через кнопку-иконку настроек
- **THEN** в контентной области снова отображается основной frontend-плагин

#### Scenario: Список секций

- **WHEN** страница настроек открыта
- **THEN** SHALL быть показаны все зарегистрированные секции с заголовком, описанием владельца и полями с человекочитаемыми названиями

#### Scenario: Редактирование значений как JSON

- **WHEN** поле секции имеет тип `json`
- **THEN** оно редактируется как JSON, а при некорректном JSON SHALL быть показана ошибка без сохранения

#### Scenario: Типизированные контролы полей

- **WHEN** секция содержит поля разных типов
- **THEN** каждое поле отображается контролом своего типа, а сохранение секции передаёт значения соответствующих типов

#### Scenario: Автосохранение дискретного поля

- **WHEN** пользователь переключает `boolean`-поле или выбирает значение `select`-поля
- **THEN** значения секции сохраняются сразу, и после перезапуска приложения отображается сохранённое значение

#### Scenario: Оболочка без UI настроек

- **WHEN** frontend-плагин настроек не загружен
- **THEN** каркас SHALL продолжать работать, а кнопка-иконка настроек оставаться доступной
