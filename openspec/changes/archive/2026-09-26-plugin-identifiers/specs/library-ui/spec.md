## MODIFIED Requirements

### Requirement: История открытых библиотек в UI

UI SHALL отображать историю открытых библиотек с указанием провайдера (source-плагина) и признака доступности библиотеки. Провайдер SHALL отображаться человекочитаемым именем (`name`) source-плагина, определённым по его идентификатору. UI SHALL показывать только записи доступных провайдеров. Выбор записи SHALL открывать соответствующую библиотеку источником этой записи.

#### Scenario: Список истории с провайдером
- **WHEN** в истории есть записи доступных провайдеров
- **THEN** UI показывает записи с указанием человекочитаемого имени провайдера и признаком доступности

#### Scenario: Недоступная библиотека
- **WHEN** библиотека из истории недоступна на диске
- **THEN** UI показывает запись с пометкой недоступности и не открывает её как рабочую

#### Scenario: Открытие из истории
- **WHEN** пользователь выбирает доступную запись истории
- **THEN** библиотека открывается источником, указанным в записи

#### Scenario: Скрытие записей отсутствующего провайдера
- **WHEN** провайдер записи недоступен
- **THEN** UI не показывает такую запись в истории
