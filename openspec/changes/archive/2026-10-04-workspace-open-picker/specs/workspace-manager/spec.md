## REMOVED Requirements

### Requirement: Активное рабочее место

**Reason**: Скрытое автоматически выбираемое «активное» место запутывает:
пользователь не видит, куда откроется книга, и должен заранее искать, какое
место «активно», чтобы не ошибиться.

**Migration**: Вместо неявного активного места приложение ведёт явное **текущее**
рабочее место (открывается только выбором пользователя). При открытии книги место
выбирается в диалоге; запуск всегда показывает список рабочих мест.

## ADDED Requirements

### Requirement: Текущее рабочее место

Приложение SHALL вести **текущее** рабочее место: то, чьи вкладки сейчас
показаны. Текущим рабочее место становится только явным действием пользователя —
выбором на экране списка, созданием или выбором при открытии книги. Автоматический
выбор текущего места по сохранённому указателю или по первому в списке SHALL NOT
выполняться. При запуске приложение SHALL показывать список рабочих мест, а SHALL
NOT восстанавливать вкладки прежнего места автоматически. Открытие книги SHALL
выполняться в текущем рабочем месте; если текущего места нет, приложение SHALL
предложить выбрать или создать рабочее место. Добавление вкладки SHALL NOT
требовать открытой библиотеки.

#### Scenario: Рабочее место становится текущим явно

- **WHEN** пользователь открывает или создаёт рабочее место
- **THEN** оно становится текущим, и показываются его вкладки

#### Scenario: Запуск показывает список

- **WHEN** приложение запускается с сохранённым реестром рабочих мест
- **THEN** показывается список рабочих мест, и ни одно из них не становится текущим автоматически

#### Scenario: Нет текущего рабочего места

- **WHEN** пользователь открывает книгу, когда текущего рабочего места нет
- **THEN** приложение предлагает выбрать или создать рабочее место, а не подставляет место само

#### Scenario: Открытие файла с диска без библиотеки

- **WHEN** пользователь открывает книгу произвольным файлом с диска, а библиотека не открыта
- **THEN** вкладка добавляется в выбранное рабочее место без ошибки и без открытия библиотеки

### Requirement: Выбор рабочего места при открытии книги

При открытии книги из библиотеки приложение SHALL предлагать выбор рабочего места:
SHALL показывать список рабочих мест с поиском по имени и возможность создать
новое. Книга SHALL открываться вкладкой в выбранном рабочем месте, которое
становится текущим. При открытии книги из уже открытого рабочего места выбор SHALL
NOT запрашиваться: книга открывается в текущем месте. Если рабочих мест нет,
выбор SHALL предлагать создать первое.

#### Scenario: Выбор рабочего места из списка

- **WHEN** пользователь нажимает «Открыть в рабочем месте» на книге и выбирает рабочее место
- **THEN** книга открывается вкладкой в выбранном месте, и оно становится текущим

#### Scenario: Создание рабочего места при выборе

- **WHEN** в диалоге выбора пользователь создаёт новое рабочее место
- **THEN** оно становится текущим, и книга открывается вкладкой в нём

#### Scenario: Поиск рабочего места

- **WHEN** пользователь вводит текст в поле поиска диалога выбора
- **THEN** список показывает только рабочие места с совпадающим именем

#### Scenario: Открытие внутри рабочего места без диалога

- **WHEN** пользователь добавляет книгу из уже открытого рабочего места
- **THEN** книга открывается вкладкой в текущем месте без запроса выбора

#### Scenario: Нет рабочих мест

- **WHEN** книга открывается, а рабочих мест ещё нет
- **THEN** выбор предлагает создать первое рабочее место

## MODIFIED Requirements

### Requirement: Создание и открытие рабочего места

Пользователь SHALL создавать рабочее место, задавая имя. Созданное рабочее место
SHALL становиться текущим и открываться. Открытие рабочего места из списка SHALL
делать его текущим и показывать его вкладки.

#### Scenario: Создание рабочего места

- **WHEN** пользователь создаёт рабочее место с именем
- **THEN** рабочее место появляется в списке, становится текущим и открывается

#### Scenario: Открытие рабочего места

- **WHEN** пользователь выбирает рабочее место в списке
- **THEN** выбранное рабочее место становится текущим, а его вкладки отображаются

### Requirement: Удаление рабочего места

Пользователь SHALL удалять рабочее место; удалённое рабочее место SHALL исчезать
из списка вместе со своими вкладками. Если удаляется текущее рабочее место,
текущего рабочего места не остаётся, и приложение показывает список рабочих мест;
автоматический выбор другого места SHALL NOT выполняться. После удаления последнего
рабочего места активного рабочего места не остаётся.

#### Scenario: Удаление рабочего места

- **WHEN** пользователь удаляет рабочее место
- **THEN** оно исчезает из списка, а его вкладки удаляются

#### Scenario: Удаление активного рабочего места

- **WHEN** пользователь удаляет текущее рабочее место, и есть другие
- **THEN** показывается список рабочих мест, а текущего места не остаётся до явного выбора

#### Scenario: Удаление последнего рабочего места

- **WHEN** пользователь удаляет последнее оставшееся рабочее место
- **THEN** список рабочих мест пуст, и текущего рабочего места нет

### Requirement: Экран списка рабочих мест

Оболочка SHALL предоставлять экран списка рабочих мест. Экран SHALL показывать
рабочие места с именем и признаком текущего и позволять создать, открыть,
переименовать и удалить рабочее место. Экран SHALL предоставлять поиск по имени
рабочего места. При пустом списке экран SHALL показывать подсказку создать рабочее
место. Экран списка SHALL показываться только с уже загруженным реестром:
начальная загрузка реестра SHALL выполняться до первого рендера оболочки. При
ошибке загрузки реестра приложение SHALL показывать отдельное состояние ошибки с
возможностью повторить загрузку и SHALL NOT показывать пустой список, потому что
«не удалось загрузить» и «рабочих мест нет» — разные состояния.

#### Scenario: Показ списка

- **WHEN** пользователь открывает экран списка рабочих мест
- **THEN** отображаются рабочие места с именами, а текущее отмечено

#### Scenario: Поиск по имени

- **WHEN** пользователь вводит текст в поле поиска на экране списка
- **THEN** список показывает только рабочие места с совпадающим именем

#### Scenario: Создание из списка

- **WHEN** пользователь создаёт рабочее место с экрана списка
- **THEN** рабочее место добавляется в список и открывается

#### Scenario: Создание из пустого состояния

- **WHEN** список рабочих мест пуст и пользователь создаёт рабочее место
- **THEN** подсказка сменяется отображением созданного рабочего места

#### Scenario: Переименование и удаление из списка

- **WHEN** пользователь переименовывает или удаляет рабочее место на экране списка
- **THEN** список отражает изменение, не покидая экран списка

#### Scenario: Список готов к первому показу

- **WHEN** приложение запускается с сохранённым реестром рабочих мест
- **THEN** при первом показе список рабочих мест уже содержит рабочие места, без промежуточного пустого состояния

#### Scenario: Ошибка загрузки реестра

- **WHEN** реестр рабочих мест не удалось загрузить при запуске
- **THEN** показывается сообщение об ошибке с кнопкой повтора, а пустой список не показывается

#### Scenario: Повтор загрузки после ошибки

- **WHEN** пользователь повторяет загрузку после ошибки, и реестр читается успешно
- **THEN** приложение показывает список рабочих мест
