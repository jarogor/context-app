# Предложение: совместимость с библиотеками Calibre

## Why

Пользователи уже имеют библиотеки в приложении Calibre и хотят пользоваться ими
в BookLib, указав готовую директорию. Сейчас приложение умеет открывать только
собственную портируемую структуру (`library.db` + вложенные папки) и обязательно
создаёт её при первом обращении, поэтому существующая Calibre-библиотека не
распознаётся и перезапись структуры каталога недопустима.

## What Changes

- **Распознавание формата при открытии:** `Library::open` определяет тип директории —
  собственная портируемая библиотека, внешняя Calibre-библиотека или пустая
  директория (создаётся собственная структура). Пустая/новая директория по-прежнему
  инициализируется как собственная библиотека, поэтому «своя система» сохраняется.
- **Поддержка чтения Calibre-библиотек в режиме «только чтение»:** Calibre-директория
  не модифицируется, команда импорта в неё отклоняется.
- **Виртуальный каталог Calibre:** при каждом запуске структура Calibre сканируется
  заново (папки авторов и книг, `metadata.opf`, файлы книг, обложки), каталог
  выстраивается в in-memory SQLite с той же схемой, что и собственная библиотека.
- **Поиск книг:** новая команда `search_books(query)` по названию и авторам работает
  для обоих типов библиотек.
- **Открытие книги во внешнем системном приложении:** новая команда открывает файл
  книги через системный обработчик (по умолчанию) — чтение во внешнем редакторе.
- **UI:** поле поиска в списке; на карточке книги действие «Открыть в системе»;
  в Calibre-режиме кнопка «Добавить EPUB» скрыта.
- **Совместимость с Calibre-структурой:** поддерживаются типовые двухуровневые
  пути Calibre `<Author>/<Title> (<id>)/` и файл `metadata.opf` стандарта EPUB.

## Capabilities

### New Capabilities

- `calibre-library`: открытие Calibre-библиотеки как read-only источника, построение
  виртуального каталога при каждом запуске (метаданные из `metadata.opf` и структуры
  папок, файлы и обложки), запрет изменений.

### Modified Capabilities

- `library-ui`: добавление поиска книг и действия «Открыть в системе»
  (открытие файла во внешнем системном приложении), скрытие импорта в
  read-only Calibre-режиме.

## Impact

- **Backend:** `Library` получает тип режима открытия; новый модуль `calibre/`
  (детекция, сканирование, разбор `metadata.opf`). Данные Calibre хранятся в памяти
  (in-memory SQLite), файлы никогда не копируются.
- **Команды:** новая `search_books`, новая `open_book_in_system`, новая
  `get_library_info`; `import_book` отклоняется в Calibre-режиме.
- **Зависимости:** добавление `quick-xml` (разбор `metadata.opf`) и `open`
  (открытие файла системным приложением).
- **Frontend:** поле поиска и действие «Открыть в системе» в `Library.svelte`.
- **Не затрагивает:** схему БД (`library.db`), портируемую структуру, плагинную
  подсистему, импорт для собственных библиотек.
