## Why

Пространство заметок сейчас работает только «внутри» книги: наборы заметок видны
лишь в рабочем месте и только для активной вкладки. Пользователь не может окинуть
взглядом всё, что он законспектировал, найти заметку по всем книгам сразу или
вернуться к нужному набору, не помня, в какой книге он лежит. По видению проекта
книги и заметки — два равноправных пространства со своим хранением, поиском и
организацией, и без реестра заметок второе пространство неполно. Данные для этого
уже есть: хранилище `notes-store` держит все наборы всех книг в одном состоянии,
но наружу отдаёт только выборку по одной книге. Не хватает только агрегата,
глобального поиска и раздела интерфейса.

## What Changes

- Новый раздел приложения **«Заметки»** (библиотека заметок) с кнопкой-иконкой в
  верхней панели: реестр наборов заметок по всем книгам, сгруппированный по
  книге, с именем набора, названием книги, числом заметок и датой изменения.
- **Глобальный поиск** по реестру и по содержимому заметок: по имени набора,
  названию книги, названию/комментарию/цитате/тексту/месту заметки.
- **Просмотр набора** из библиотеки: раскрытие списка заметок набора (тип,
  имя, превью, место, дата, цвет) и **переход** — открыть книгу набора в рабочем
  месте и перейти к набору/заметке.
- Хранилище `notes-store` получает **агрегатную операцию** `list_all_sets`
  (сводки всех наборов всех книг) и **отображаемые метаданные книги**: набор
  несёт необязательное название книги, которое оболочка задаёт при создании и
  которое возвращается в сводках. Ключ книги остаётся **непрозрачным** — реестр
  не закладывается на «путь = книга», чтобы будущая умная идентификация книги
  сменила источник ключа без правки хранилища и реестра.
- Данные реестра загружаются **на бутстрапе**, как и прочие встроенные
  поверхности (`AGENTS.md`).

Не входит в этот шаг: подборки/вкладки наборов, импорт/экспорт и обмен наборами
(`notes-io`), умная идентификация книги (`book-identity`) — отдельные изменения.

## Capabilities

### New Capabilities

- `notes-library`: реестр наборов заметок по всем книгам с названием книги,
  глобальный поиск по наборам и заметкам, просмотр набора и переход к книге и
  заметке в рабочем месте, отдельный раздел приложения «Заметки».

### Modified Capabilities

- `notes-store`: добавляется агрегатная операция реестра (`list_all_sets`) и
  необязательные отображаемые метаданные книги у набора (название книги).
- `app-shell`: в верхнюю панель добавляется кнопка-иконка раздела «Заметки»,
  контентная область переключается на новый раздел, заголовок раздела меняется.

## Impact

- **Плагин** `src-wasm-plugins/notes-store/` (`lib.rs`, `store.rs`, `models.rs`,
  тесты): новая операция агрегата, поле названия книги, нормализация состояния.
- **Фронтенд**: новый вертикальный срез `src/features/notes-library/` (клиент
  реестра + страница/панель + тесты); `src/features/notes/notes.ts` расширяется
  операцией реестра и передачей названия книги при создании набора; `App.svelte`
  — раздел, состояние и переход; `bootstrap.ts` — загрузка реестра.
- **Верхняя панель** `App.svelte` — новая кнопка раздела.
- **Спеки**: `openspec/specs/notes-store/`, `openspec/specs/app-shell/`, новая
  `openspec/specs/notes-library/`.
- **Совместимость данных**: состояние `notes-store` расширяется необязательными
  полями; старые данные читаются (название книги отсутствует — показывается
  резервное имя по ключу). Миграция не требуется.
- **Тесты**: Rust-тесты плагина (агрегат, метаданные книги), Vitest
  (`notes-library`, `notes`), e2e (раздел, поиск, переход), мок-мост
  `packages/testing`.
