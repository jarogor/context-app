## Context

Интерфейс собирался из общих компонентов `@texture/ui` непоследовательно (см.
`proposal.md` — Why). Дизайн-система построена на shadcn-svelte поверх примитивов
Bits UI и токенов Tailwind v4; `Checkbox` уже использовал Bits UI, а выпадающие
списки — нет. Токены оформления живут в `packages/ui/src/tokens.css` и идут
палитрами (Gruvbox по умолчанию, Mist).

## Goals / Non-Goals

**Goals:**

- Один компонент `Select` на Bits UI вместо нативного `<select>` во всех
  областях.
- Единая политика обводок и интерактивных состояний через общий токен `--border`.
- Единый набор действий над сущностью: общие иконочные кнопки и контекстное меню.

**Non-Goals:**

- Новые палитры, темы и иная визуальная концепция — оформление не меняется.
- Поведение областей (какие действия доступны) не меняется, кроме способа
  показа выпадающего списка.
- Автономные frontend-плагины и их интерфейсы.

## Decisions

- **`Select` на `bits-ui` `Select` с API `items: { value, label }[]`.** Альтернатива
  — стилизованный нативный `<select>` — отклонена: раскрытый список рисует ОС и не
  подчиняется токенам. API с массивом элементов совпадает с уже принятым в
  `PackageSelector` и упрощает миграцию.
- **`--input` приравнен к `--border` (15 %).** Альтернатива — оставить отдельный
  более контрастный цвет у полей — отклонена: пользователь просил одну мягкую
  обводку везде; hover/выбор показываются фоном, а не рамкой.
- **`ActionMenu` — контекстное меню на `bits-ui` `DropdownMenu` с пунктами
  вторичных действий над сущностью; отдельные `EditButton`/`DeleteButton` — для
  одиночных правок.** Альтернатива — оставить рядом стоящие текстовые кнопки —
  отклонена: случайное нажатие удаления слишком вероятно, а место занимается.
- **Тесты Bits UI в jsdom требуют заглушек Pointer Capture** — добавлены в
  `vitest.setup.ts` корня и `packages/ui`; в браузерных сценариях примитивы
  работают штатно.

## Risks / Trade-offs

- [Bits UI в jsdom не имеет Pointer Capture] → заглушки `hasPointerCapture`/
  `setPointerCapture`/`releasePointerCapture` в двух setup-файлах.
- [Визуальный эталон устаревает] → обновляется `playwright --update-snapshots`;
  сравнение остаётся строгим.
- [Миграция `select` → `Select` затрагивает декларативный рендерер] → покрыто
  компонентными тестами `Select` и браузерными сценариями настроек.
