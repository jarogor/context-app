## Context

См. `proposal.md` — Why. Сейчас `App.svelte` держит `.notifications-region`, доканный слева: `collapsed` (полоса 40px) / `expanded` (400px) / `page`. `notifications-ui` рисует саму полосу с вертикальной надписью и счётчиком и управляет state через layout-сообщения. Оболочка не должна рисовать счётчик (спека `notifications`), поэтому кнопку рисует плагин.

## Goals / Non-Goals

**Goals:**

- Компактная точка входа: кнопка со счётчиком в верхней панели, панель справа скрыта по умолчанию.
- Сохранить заметность счётчика и всё текущее содержимое панели.
- Оставить мобильную страницу без изменений.

**Non-Goals:**

- Изменение журнала, операций и модели уведомлений.
- Слоты для нескольких кнопок плагинов в панели.
- Уведомления «тостами» поверх контента.

## Decisions

### 1. Один iframe: кнопка в панели → панель справа

Регион уведомлений — один `PluginFrame`. В состоянии `button` он вставлен flex-элементом в верхнюю панель слева от кнопки настроек; в состоянии `expanded` тот же узел становится `position: fixed` справа ниже панели; в `page` — на всю область ниже панели. Смена позиционирования не пересоздаёт iframe, поэтому состояние плагина сохраняется.

Альтернатива — рисовать кнопку в оболочке — отклонена: спека `notifications` запрещает оболочке содержать код счётчика.

### 2. Скрытая панель вместо свёрнутой полосы

Состояние `collapsed` удаляется. По умолчанию панель скрыта, виден только `button`. Открытие/закрытие — клик по кнопке/кнопке закрытия. `notifications-ui` больше не рисует вертикальную полосу.

### 3. Смещение контента

При `expanded` контентная область получает `margin-right: 400px`, чтобы панель была докованной, а не оверлеем. В `button`/`page` смещения нет.

## Risks / Trade-offs

- [Кнопка исчезает из панели, пока открыта панель] → закрытие панели возвращает кнопку; панель визуально занимает место справа, кнопка настроек остаётся на месте.
- [Позиционирование iframe в панели через `position` требует аккуратной высоты] → в `button` задаётся фиксированная высота 36px, в `expanded`/`page` — на всю область ниже панели.
- [Mobile и desktop используют разные состояния одного плагина] → переключение по ширине окна, как сейчас.

## Migration Plan

1. Обновить `App.svelte`: слот в панели, состояния `button`/`expanded`/`page`, смещение контента.
2. Переписать `notifications-ui`: кнопка со счётчиком, панель справа без сворачивания, удалить полосу.
3. Пересобрать frontend-плагины, обновить спеки и документацию, выполнить проверки.
