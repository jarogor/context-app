## Context

См. `proposal.md` — Why и разбор в `_docs/history/2026-09-30-2342-workspace-book-independence.md`.

Прежняя модель: вкладка хранила `bookId` каталога активной библиотеки, а чтение
шло через `PluginSession` этой библиотеки. Сессия создаётся с `active_plugin = None`
и без `select_source` возвращает «plugin не выбран»; песочница `fs_read_bytes`
ограничивала чтение корнем библиотеки. Поэтому восстановленная вкладка без
открытой библиотеки ломалась, а произвольный файл прочитать было нельзя.

## Goals / Non-Goals

**Goals:**
- Сделать вложение вкладки путём к файлу; рабочее место не знает библиотеку.
- Читать книгу по пути независимо от открытой библиотеки.
- Открывать произвольный файл с диска и переуказывать недоступную книгу любым
  файлом.
- Держать заметки привязанными к книге (ключ — путь), общими для всех вкладок.

**Non-Goals:**
- Стабильная идентификация книги по содержимому (`book-identity`) — ключ заметок
  пока путь; смена источника ключа произойдёт без правки хранилища заметок.
- Плагины рабочего места с рисованием (PDF) — механизм сохраняется, формат —
  следующий шаг.
- Реестр всех наборов заметок и обмен (`notes-library`, `notes-io`).

## Decisions

### Вложение вкладки — путь к файлу

`WorkspaceTab` хранит `path`, `title`, `format`, `zoom`, `position`, `mode`;
`BookRef` — `path`, `title`, `format?`. Ядро (`workspace_state.rs`) хранит вкладку
с полем `path`; для миграции прежних снимков — `#[serde(default, alias = "book_id")]`.
Книга из библиотеки и файл с диска — единый случай: рабочее место не различает
источник, поэтому состояние «библиотека книги не открыта» недопустимо.

### Отдельный runtime чтения

В `AppState` появляется ленивый `reader: Option<PluginRuntime>` с настройками
`ReaderConfig` (директории плагинов, отключённые, корень служебного хранилища,
кэш компиляции). Runtime собирается при первом обращении из source- и
workplace-плагинов (`PluginRuntime::load_filtered`), без привязки к активной
сессии библиотеки. Это снимает зависимость чтения от `select_source`.

### Песочница на директорию файла

Чтобы не давать source-плагину произвольный доступ, `apply_sandbox` канонизирует
путь книги, ставит корнем песочницы её директорию, а плагину передаёт имя файла
(`{ "path": <имя файла> }`). Так плагин читает ровно выбранный файл, оставаясь в
своём контракте `fs_read_bytes`/`import_read_bytes`.

### Формат по расширению пути

`formatFromPath` извлекает расширение и приводит к нижнему регистру. Встроенное
чтение — EPUB; для форматов, обслуживаемых плагином рабочего места, выбирается
плагин по `reader_plugin_for_format`. Признак формата из каталога книги больше не
используется.

### Переуказание недоступной книги

`ReaderPage` при ошибке чтения показывает заглушку «Книга недоступна» с кнопками
«Указать файл» и «Убрать вкладку». «Указать файл» открывает системный диалог
выбора **любого** файла (`openDialog`), как при добавлении вложения; после выбора
`replaceTabBook` меняет путь, сохраняя позицию и масштаб. Никаких действий втихую:
библиотека не открывается автоматически, книга не подменяется молча.

### Ключ заметок — путь

`bookKey(path)` заменяет прежний `libraryPath::bookId`. Одна книга в разных
вкладках (и в разных рабочих местах) получает общий набор заметок и подсветок.
После появления `book-identity` сменится только источник ключа, хранилище заметок
(`notes.store@1`) не изменится, так как ключ для него непрозрачен.

### Библиотечный UI поставляет абсолютный путь

`BookPage.svelte` складывает `libraryRoot` (из `active_library`) и относительный
`BookFiles.path` и передаёт абсолютный путь сообщением `workspace:open-book`.
Список форматов для показа действия «Открыть в рабочем месте» берётся из
`reader_formats`, а не из библиотечного каталога.

## Risks / Trade-offs

- [Песочница на директорию файла временно расширяет корень] → корнем становится
  только директория выбранного файла; произвольный доступ не открывается.
- [Кэш содержимого по пути устаревает при переуказании] → после переуказания
  вызывается `reader_forget_book` для прежнего пути.
- [Прежние снимки вкладок без пути] → читаются как недоступные и предлагают
  указать файл; состояние чтения сохраняется.
- [Пустой корень библиотеки у внешнего каталога] → путь складывается из корня
  активной библиотеки и относительного пути книги; при отсутствии корня действие
  открытия недоступно.

## Migration Plan

1. Ввести `ReaderConfig`/ленивый runtime и команды `reader_*`; удалить
   `commands/workplace.rs`.
2. Перевести `workspace_state.rs` на `path` с алиасом `book_id`.
3. Перевести фронтенд (`workplace.ts`, `reader/index.ts`, `ReaderPage`,
   `WorkplaceSurface`, `WorkplaceTabs`, `App.svelte`) на путь.
4. Передать абсолютный путь из `library-ui`.
5. Обновить мок, тесты и документацию. Откат — вернуть прежнюю модель `bookId`
   и чтение через сессию библиотеки; хранилище заметок не меняется.
