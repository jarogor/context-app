## MODIFIED Requirements

### Requirement: Виртуальный каталог Calibre-библиотеки

Приложение SHALL строить виртуальный каталог книг из структуры Calibre-библиотеки при первом открытии или при необходимости полной перестройки: папок книг, метаданных из `metadata.opf`, файлов содержимого и обложек. При последующих открытиях приложение SHALL использовать согласованный индекс из `.booklib`, проверять изменения источника и SHALL актуализировать только затронутые записи, если полная перестройка не требуется. Каталог SHALL содержать для каждой книги название, авторов, файлы содержимого и путь к обложке.

#### Scenario: Книга с метаданными

- **WHEN** в Calibre-библиотеке есть книга с `metadata.opf`, файлом содержимого и обложкой
- **THEN** виртуальный каталог содержит запись книги с названием, авторами из `metadata.opf`, файлом содержимого и обложкой

#### Scenario: Книга без обложки

- **WHEN** в папке книги Calibre отсутствует файл обложки
- **THEN** книга присутствует в каталоге без обложки

#### Scenario: Повторное открытие без изменений

- **WHEN** приложение повторно открывает Calibre-библиотеку, для которой существует актуальный локальный индекс и не обнаружены изменения
- **THEN** каталог восстанавливается из индекса без полного сканирования всех книг

#### Scenario: Новая книга после предыдущего открытия

- **WHEN** после предыдущего открытия в библиотеке появилась новая книга
- **THEN** каталог дополняется новой книгой после инкрементальной синхронизации или проверки при открытии

#### Scenario: Повторное сканирование при запуске

- **WHEN** приложение запускается повторно с той же Calibre-библиотекой, в которой появились новые книги или папки, а индекс отсутствует, повреждён или признан несовместимым
- **THEN** виртуальный каталог строится заново и отражает текущее содержимое Calibre-библиотеки
