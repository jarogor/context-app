## ADDED Requirements

### Requirement: Интерфейс активной библиотеки

Библиотечный UI SHALL отображать книги активной библиотеки и обновлять их при
открытии библиотеки. Библиотечный UI SHALL NOT содержать выбор библиотеки и
историю открытий — это принадлежит странице «Библиотеки» на уровне оболочки. При
отсутствии активной библиотеки UI SHALL показывать подсказку открыть библиотеку на
странице «Библиотеки».

#### Scenario: Открытие библиотеки снаружи

- **WHEN** библиотека открыта на странице «Библиотеки»
- **THEN** библиотечный UI перезагружает и показывает книги активной библиотеки

#### Scenario: Нет активной библиотеки

- **WHEN** активная библиотека не выбрана
- **THEN** UI показывает подсказку открыть библиотеку на странице «Библиотеки»

## REMOVED Requirements

### Requirement: История открытых библиотек в UI

**Reason**: Выбор библиотеки и история перенесены на системную страницу
«Библиотеки» на уровне оболочки: это уровень приложения, а не содержимое книги.

**Migration**: Такие же операции доступны на странице «Библиотеки»
(`app-shell`): список истории с временем, открытие из истории, открытие новой
папки и удаление записи.
