## Why

Построение индекса большой библиотеки занимает заметное время, но UI показывает
лишь неопределённую «крутилку»: пользователь не понимает, сколько ждать. Схема
индекса создаётся «на месте» через `CREATE TABLE IF NOT EXISTS`, поэтому добавить
книгам новые свойства (рейтинг, подборки, поля для поиска) можно только ценой
пересоздания базы. Кроме того, обложки не входят в индекс: UI извлекает их вживую
по каждой карточке, из-за чего открытие и переключение библиотеки выглядят как
повторное сканирование и приводят к зависанию.

## What Changes

- **Миграции схемы.** Схема индекса source-плагина SHALL управляться
  упорядоченными версионированными миграциями через `PRAGMA user_version`:
  новые свойства книг добавляются новой миграцией, без пересоздания и перестройки
  индекса. **BREAKING**: прежняя «топорная» схема заменяется управляемой
  миграциями; неизвестная/несовместимая версия приводит к полной перестройке.
- **Индекс включает всё о книге.** Обложка сохраняется в индексе в том же проходе,
  что и метаданные (она и так извлекается при чтении файла), а операция `cover`
  отдаёт её из индекса — без повторного чтения и разбора файлов.
- **Детерминированный прогресс.** Перед чтением source-плагин дешёво перечисляет
  файлы и знает общий объём; затем обрабатывает книги по одной и публикует
  прогресс (`{done, total}`). UI показывает прогресс-бар с процентами. Если
  индекс актуален, прохода нет и прогресс не показывается.
- **Без фонового дозаполнения.** Библиотека не наполняется динамически: индекс
  строится одним измеряемым проходом.

## Capabilities

### New Capabilities

- Отсутствуют: новых контрактов не вводится, меняется поведение существующих.

### Modified Capabilities

- `library-index-cache`: схема индекса управляется версионированными миграциями;
  индекс включает обложку; построение индекса публикует детерминированный прогресс.
- `library-ui`: во время построения индекса UI показывает определённый прогресс
  (проценты), а не неопределённую «крутилку».

## Impact

- WASM-плагины: новый общий crate миграций в workspace `src-wasm-plugins/`;
  `src-wasm-plugins/library/`, `src-wasm-plugins/library-calibre/` (схема, обложка
  в индексе, прогресс, `emit_event` в host-функциях).
- Ядро: `src-tauri/src/plugin/` — прогресс доставляется существующим opaque
  relay (`emit_event`), новый host-контракт не требуется; при необходимости
  уточняется `_docs/plugin-contract.md`.
- Скрипты сборки: `scripts/build-wasm-plugins.sh` (host-функция `emit_event` для
  source-плагинов).
- UI: `plugins/library-ui/`, `src/lib/LibrariesPage.svelte` (прогресс-бар).
- Документация: `_docs/library-index.md`, `_docs/plugin-contract.md`.
