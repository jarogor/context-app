## Why

У приложения есть пространство книг (библиотека), но нет рабочего места, где
книга открывается и читается. Сейчас «чтение» живёт внутри frontend-плагина
библиотеки как примитивный текстовый просмотр и не является отдельной страницей
уровня оболочки. По `ROADMAP.md` Рабочее место — точка сборки ценности проекта:
именно здесь книга и заметки сходятся вместе. Нужен первый шаг: рабочая страница
книги с областью отображения, из которой позже вырастет общий интерфейс для
форматных плагинов (книга → библиотека → заметки).

## What Changes

- Добавляется рабочая страница чтения (`ReaderPage`) уровня оболочки — одна из
  главных рабочих страниц наряду с библиотекой и, в будущем, заметками.
- Верхняя панель на странице чтения: кнопка «назад» в библиотеку вместо логотипа,
  затем название открытой книги; кнопки уведомлений и настроек остаются
  доступны. Кнопка выбора библиотек на рабочей странице не показывается.
- Область отображения книги: EPUB-главы как стилизованный безопасный HTML
  (картинки, базовое оформление), непрерывная прокрутка. Формат — EPUB; для
  других форматов страница показывает информативный отказ и действие «открыть в
  системе».
- Нижняя панель состояния: масштаб (размер шрифта) и прогресс чтения в
  процентах. Постраничная навигация — в перспективе, не в этом изменении.
- Открытие: клик по карточке книги по-прежнему открывает файл в системном
  приложении; встроенная читалка открывается явной кнопкой «Читать» (для EPUB).
- Внутренний шов для будущего форматного плагина: страница работает через общий
  интерфейс читалки, EPUB — первая реализация; вынесение в WASM-плагин —
  отдельный следующий шаг.
- Примитивный read-view внутри `library-ui` заменяется открытием страницы чтения
  оболочки.

## Capabilities

### New Capabilities

- `reader`: рабочая страница чтения книги — шапка с возвратом и названием,
  область отображения EPUB, нижняя панель (масштаб, прогресс), общий интерфейс
  для будущих форматов и отказ для неподдерживаемых.

### Modified Capabilities

- `app-shell`: оболочка поддерживает страницу чтения как контентную поверхность;
  верхняя панель на этой странице показывает кнопку возврата и название книги
  вместо логотипа/имени библиотеки; нижняя панель состояния.
- `library-ui`: открытие книги встроенным чтением заменяется на открытие
  страницы чтения по явной кнопке «Читать»; клик по карточке остаётся открытием
  в системе.

## Impact

- Фронтенд: `src/App.svelte` (страница чтения, состояние), новые компоненты в
  `src/lib/` (`ReaderPage.svelte` и части области/панели), `packages/ui`
  (нужные компоненты/токены, если потребуется).
- Frontend-плагин `plugins/library-ui`: удаление `Reading.svelte`, кнопка
  «Читать», передача события открытия книги в оболочку.
- Source-плагин `library` (`src-wasm-plugins/library`): операция, отдающая
  структурированное содержимое EPUB (главы/ресурсы) вместо только плоского
  текста; переиспользование существующего разбора EPUB.
- e2e/компонентные тесты: мок-мост, сценарии открытия читалки.
- Спеки: новые `reader`; изменения `app-shell`, `library-ui`.
- Не входит в это изменение: постраничная навигация, сохранение позиции между
  запусками, заметки, вынесение чтения в отдельный WASM-плагин.
