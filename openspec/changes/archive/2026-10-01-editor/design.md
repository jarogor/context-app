## Context

См. `proposal.md` — Why. Требования — в `specs/editor/spec.md`.

Прежний срез `editor` читал заметки как записи к проценту прокрутки, набираемые
в панели. Это противоречит задаче инструмента: работать **внутри книги**.
Настоящий срез меняет модель на **цитаты-выделения**.

Базовый плагин `notes-store` (capability `notes.store@1`) уже хранит заметку с
непрозрачным якорем, цитатой и метаданными места и публикует `notes:changed`.
Ядро маршрутизирует операции generic-командой `invoke_base_plugin_operation`.

Читалка сейчас собирает документ книги в строку HTML и показывает его в
`iframe` с `sandbox="allow-scripts"`, ведя позицию в процентах. Родитель не имеет
доступа к документу (нет `allow-same-origin`), поэтому выделение в тексте
недоступно. HTML глав уже очищен от `<script>` source-плагином, поэтому документ
можно показывать без sandbox и работать с ним напрямую.

## Goals / Non-Goals

**Goals:**
- Создавать заметку-цитату выделением на странице и точно восстанавливать это
  выделение.
- Подсвечивать выделения заметок прямо в тексте книги.
- Дать список цитат с местом и датой, поиском, переходом к месту и удалением.
- Сохранить принцип «заметка привязана к книге, а не к вкладке».

**Non-Goals:**
- Пользовательский текст заметки, рисунки и записи на странице — следующие срезы.
- Реестр всех наборов, подборки и обмен (`notes-library`, `notes-io`).
- Стабильная идентификация книги (`book-identity`); ключ книги пока формирует
  оболочка.
- Страничный режим чтения (отдельный домен); сейчас непрерывная прокрутка, а
  номер страницы для EPUB приближён.

## Decisions

### Заметка-цитата вместо записи у позиции

Содержание заметки — выделенный текст. Пользователь ничего не набирает в
стороне: это отличает работу «внутри книги» от блокнота. Хранимый текст (`text`)
не используется; вместо него — цитата (`quote`).

### Точный якорь выделения

Заметка получает **непрозрачный якорь**, сериализующий выделение так, чтобы его
можно было восстановить без смещения:

- `chapter` — индекс главы книги;
- `start`/`end` — путь к узлу-текстовому узлу (индексы в `childNodes`) и
  смещение символа;
- `quote` — выделенный текст (для отображения и запасного поиска);
- `percent` — доля позиции выделения в книге (десятичная), для форматов без
  страниц и перехода при несовпадении;
- `page` — номер страницы для страничных форматов (пока пусто для EPUB).

Якорь адресует **текстовый узел**, а не пиксели, поэтому не зависит от размера
окна, переносов и масштаба. Путь к узлу вычисляется по документу и устойчив,
пока структура главы неизменна.

### Модуль чтения с доступом к документу

Документ книги переезжает в модуль `BookReader` (Svelte-компонент): он собирает
HTML глав, показывает его в `iframe` **без sandbox** (HTML уже без скриптов),
получает доступ к `contentDocument` и отвечает за:

- выделение диапазона пользователем и создание цитаты;
- отрисовку подсветок заметок;
- переход к якорю и показ выделения;
- масштаб (с удержанием верхней строки) и позицию (проценты) с отчётом наружу.

Это отделяет ответственную логику работы с документом от страницы рабочей
области (`ReaderPage`).

### Создание заметки сразу

Выделение создаёт заметку немедленно — без лишнего нажатия. Позже рядом с
выделением появится место для дописывания, но контракт якоря при этом не
меняется.

### Место заметки: страница или доля

Отображаемое место — номер страницы для страничных форматов (PDF, следующий
приоритет) и доля позиции с десятичной точностью для форматов без страниц.
Модель хранит оба; панель показывает подходящее.

### Панель — список цитат

Панель показывает цитату, имя (из текста цитаты либо «Заметка N» при пустой
цитате), место и дату. Набор выбирать не нужно: книга заводит набор по
умолчанию (`Основные`), панель работает с ним.

## Risks / Trade-offs

- [Путь к узлу зависит от структуры главы] → при несовпадении есть запасной
  поиск по цитате и переход по проценту; якорь непрозрачен и заменяем.
- [Приближённый номер страницы для EPUB] → главная цель — страничные форматы;
  для EPUB показывается доля позиции, страница появится со страничным режимом.
- [Показ недоверенного HTML без sandbox] → HTML глав уже очищен от скриптов
  source-плагином; риск ограничен содержимым книги.
- [Пересекающиеся выделения] → подсветки накладываются; отдельный случай
  (склейка цитат) — за пределами среза.

## Migration Plan

1. Добавить модуль `BookReader` и перевести `ReaderPage` на него.
2. Создать заметку-цитату из выделения и сохранить якорь.
3. Отрисовывать подсветки заметок и переходить к месту.
4. Перевести панель на список цитат (цитата, место, дата, поиск, удаление).
5. Обновить мок, тесты, документацию; откат — вернуть прежнюю читалку, хранилище
   заметок не меняется.

## Open Questions

- Точная привязка «страниц» EPUB и совместимость с PDF — вместе со страничным
  режимом чтения (`book-identity`/плагины форматов).
- Общий или раздельный набор заметок для одной книги в разных библиотеках —
  решается в `library-manager`/`book-identity`.
