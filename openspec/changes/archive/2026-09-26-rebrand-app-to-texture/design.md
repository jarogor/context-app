## Context

См. `proposal.md` — Why. Текущее имя «Jarogor BookLib»/«BookLib» зашито в четырёх
слоях: пользовательские области (верхняя панель `src/App.svelte`, `<title>`,
заголовок окна Tauri, текст приветствия в `src-tauri/src/lib.rs`), конфигурация
Tauri (`productName`, `identifier`), метаданные пакетов (Cargo, npm, scope
`@booklib/*`) и тесты/документация. E2E-тесты ищут текст «BookLib» и сравнивают
скриншот с эталоном, поэтому ренейм обязан быть сквозным.

Отдельное ограничение — каталог данных: Tauri выводит его из `identifier`,
поэтому смена идентификатора меняет расположение состояния приложения.

## Goals / Non-Goals

**Goals:**

- Одно отображаемое имя «Текстура» на всех пользовательских областях и
  единый технический идентификатор `Texture`/`texture` в именах артефактов.
- Новый bundle identifier `ru.jarogor.texture`.
- Полный проход по коду, конфигурации, пакетам, тестам и документации, чтобы
  старый бренд не остался в исходниках.

**Non-Goals:**

- Автоматическая миграция пользовательских данных из старого каталога.
- Переименование исторических артефактов: `openspec/changes/archive/`,
  `src-tauri/target/`, `dist/`, `public/plugins/`, `dev_data/`.
- Смена структуры каталогов и имён плагинов (`library`, `settings`, ...) — они не
  содержат бренда.
- Новый логотип/иконки (используются существующие `icons/*`, favicon).

## Decisions

### 1. Разделение отображаемого и технического написания

В пользовательских областях используется кириллица «Текстура», в технических
именах — латинское «Texture»/«texture». Соответствие:

| Место | Значение |
| --- | --- |
| Верхняя панель, `<title>`, заголовок окна, приветствие | «Текстура» |
| `productName` (имена пакетов/бинарей бандла) | `Texture` |
| Cargo-пакет / библиотека | `jarogor-texture` / `jarogor_texture_lib` |
| Корневой npm-пакет | `jarogor-texture` |
| npm-пакеты frontend-плагинов | `jarogor-texture-<name>` |
| npm-scope общих пакетов | `@texture/*` |
| bundle identifier | `ru.jarogor.texture` |
| Канал `postMessage` оболочки и frontend-плагинов | `texture-plugin` |

`productName` оставлен латиницей, потому что из него Tauri выводит имена
дистрибутивов (`.deb`, `.AppImage`, имя `.app`), и кириллица там создаёт риск
некорректной упаковки. Пользовательское имя всё равно берётся из явного
`title` окна и UI. Альтернатива — `productName: "Текстура"` — отклонена из-за
риска в бандлинге; цена решения — имя приложения в системном меню macOS будет
латинским (приемлемо на текущем этапе).

### 2. Смена bundle identifier и отсутствие миграции

Идентификатор меняется на `ru.jarogor.texture`; каталог данных приложения
меняется, старое содержимое не переносится. Это осознанное решение: проект
пребета, а смена идентификатора — ожидаемая часть ребрендинга. Фиксируем
поведение явно, чтобы «исчезновение» прежних библиотек не считалось дефектом.
Альтернатива — оставить `com.jarogor.booklib` — отклонена: бренд остался бы в
идентификаторе и путях данных.

### 3. Переименование npm-scope через workspace

Scope `@booklib/*` (`ui`, `ui-schema`, `testing`) меняется на `@texture/*`
одновременно в `package.json` пакетов, во всех импортах, `vite.config.ts`,
`global.css` и корневом `package.json`. Lockfile пересобирается `npm install`.
Альтернатива — оставить scope — отклонена: это видимое техническое имя бренда.

### 4. Порядок и верификация

Правки идут конфигурация → Rust → frontend/пакеты → тесты → документация, с
финальным поиском остатков `BookLib`/`booklib`/`Jarogor` по исходникам и прогоном
штатных проверок (`cargo test/clippy/fmt`, `npm run check`, `npm test`,
`npm run test:e2e`, `npm run build`, `openspec validate --all`). E2E-эталон
скриншота перегенерируется осознанно (изменился текст в шапке).

## Risks / Trade-offs

- [Ложный остаток бренда в импортах/конфигах] → финальный поиск по репозиторию и
  сборка; компилятор ловит битые импорты `@booklib/*`, npm — отсутствующие
  workspace-пакеты.
- [Сломанный e2e-снимок из-за смены текста] → эталон пересоздаётся, проверка
  идёт по новому эталону.
- [Потеря пользователем прежних данных из-за нового identifier] → поведение
  зафиксировано в proposal/design; ручной перенос каталога остаётся возможным,
  но не входит в изменение.
- [Кириллица в UI оболочки на узком экране] → текст короче прежнего «BookLib»,
  вёрстка не ухудшается; скриншот-тест это подтверждает.

## Migration Plan

1. Сменить `identifier`/`productName`/`title` в `tauri.conf.json` и тексты UI.
2. Переименовать Rust-crate и npm-пакеты, обновить импорты и lockfile.
3. Обновить e2e-тесты и перегенерировать эталон, поправить документацию.
4. Проверки из `AGENTS.md`; при необходимости — ручной перенос каталога данных.
   Откат — revert коммита (возврат старого identifier вернёт прежний каталог).
