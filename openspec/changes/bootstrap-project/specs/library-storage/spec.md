# library-storage

## Purpose

Определение переносимой структуры директории библиотеки и схемы SQLite-БД, обеспечивающих полную автономность и перенос библиотеки между устройствами без миграций и обращения к сети.

## ADDED Requirements

### Requirement: Переносимая структура директории библиотеки

Вся библиотека SHALL храниться в одной директории, включающей файл SQLite-базы, папки для файлов книг, обложек и плагинов. Все пути к файлам, сохраняемые в БД, SHALL быть относительными к корню директории библиотеки.

#### Scenario: Открытие библиотеки по корректной структуре

- **WHEN** приложение открывает директорию, содержащую файл SQLite-базы и папки книг, обложек и плагинов
- **THEN** приложение работает с этой директорией как с библиотекой без выполнения миграций

#### Scenario: Перенос директории на другое устройство

- **WHEN** пользователь копирует директорию библиотеки на носитель и открывает её на другом устройстве
- **THEN** приложение продолжает корректно работать с копией без обращения к сети и без изменений в данных

### Requirement: Схема БД для базовых сущностей

База данных SHALL содержать сущности «книга», «автор», «серия», «тег» и «файл», а также связи многие-ко-многим между ними. Каждая сущность SHALL иметь уникальный идентификатор и базовые атрибуты для отображения и поиска.

#### Scenario: Хранение книг с авторами, серией и тегами

- **WHEN** в базе создаётся книга с авторами, серией и тегами
- **THEN** все связи книги сохраняются и могут быть восстановлены при чтении

#### Scenario: Связь книги с файлами

- **WHEN** для книги сохраняется файл содержимого и файл обложки
- **THEN** записи о файлах ссылаются на книгу и содержат относительные пути в портируемой директории

### Requirement: Автономная работа без сети

Все операции чтения и записи библиотеки SHALL выполняться локально; доступ к сети для работы с библиотекой SHALL не требоваться.

#### Scenario: Работа с библиотекой в офлайн-режиме

- **WHEN** приложение работает при полностью отключённой сети
- **THEN** все операции со списком книг, метаданными и файлами выполняются без ошибок, связанных с сетью
