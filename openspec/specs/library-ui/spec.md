# library-ui Specification

## Purpose

Графический интерфейс десктопного приложения для отображения списка книг библиотеки и страницы книги с информацией о ней и действиями открытия.

## Requirements

### Requirement: Просмотр списка книг

UI SHALL отображать список всех книг библиотеки с базовой информацией: названием, авторами и обложкой. Если обложка не извлечена, UI SHALL показывать картинку-заглушку вместо пустого блока. При пустой библиотеке UI SHALL показывать информативное пустое состояние.

#### Scenario: Отображение книг в списке

- **WHEN** библиотека содержит хотя бы одну книгу
- **THEN** UI показывает список книг, и для каждой книги отображаются название, авторы и обложка

#### Scenario: Книга без обложки

- **WHEN** у книги не извлечена обложка
- **THEN** вместо обложки отображается картинка-заглушка

#### Scenario: Пустая библиотека

- **WHEN** библиотека не содержит книг
- **THEN** UI показывает пустое состояние с подсказкой о том, как добавить книгу

### Requirement: Страница книги

UI SHALL открывать страницу книги по клику на карточку книги. Страница книги
SHALL показывать информацию о книге: обложку, название и авторов. Страница книги
SHALL предоставлять действия открытия книги: «Открыть в рабочем месте» — для
форматов, для которых установлен включённый плагин рабочего места, и «Открыть в
системе». Действие «Открыть в рабочем месте» SHALL NOT показываться для формата,
не поддерживаемого установленными плагинами. Возврат со страницы книги SHALL
показывать список книг с сохранённым поиском.

#### Scenario: Открытие страницы книги

- **WHEN** пользователь нажимает на карточку книги
- **THEN** открывается страница книги с обложкой, названием и авторами

#### Scenario: Действия открытия на странице книги

- **WHEN** открыта страница книги
- **THEN** доступны действия «Открыть в рабочем месте» (для формата с установленным плагином рабочего места) и «Открыть в системе»

#### Scenario: Чтение со страницы книги

- **WHEN** пользователь нажимает «Открыть в рабочем месте» на странице книги поддерживаемого формата
- **THEN** книга добавляется вкладкой в рабочее место

#### Scenario: Неподдерживаемый формат

- **WHEN** формат книги не поддерживается ни одним установленным плагином рабочего места
- **THEN** действие «Открыть в рабочем месте» на странице книги не показывается, а «Открыть в системе» остаётся доступным

#### Scenario: Возврат к списку книг

- **WHEN** пользователь нажимает возврат на странице книги
- **THEN** снова показывается список книг с сохранённым поиском

### Requirement: Передача пути книги в рабочее место

Действие «Открыть в рабочем месте» на странице книги SHALL передавать рабочему
месту **абсолютный путь** файла содержимого книги: корень активной библиотеки,
соединённый с относительным путём файла книги. Список форматов, для которых
показывается действие, SHALL определяться по форматам, доступным встроенному
чтению и плагинам рабочего места, а не по признаку книги в каталоге библиотеки.

#### Scenario: Абсолютный путь книги

- **WHEN** пользователь нажимает «Открыть в рабочем месте» на книге активной библиотеки
- **THEN** рабочее место получает абсолютный путь файла книги и открывает её вкладкой

#### Scenario: Поддержка формата по читалке

- **WHEN** формат книги поддерживается встроенным чтением или плагином рабочего места
- **THEN** действие «Открыть в рабочем месте» показывается для этой книги

#### Scenario: Неподдерживаемый формат

- **WHEN** формат книги не поддерживается ни встроенным чтением, ни плагинами рабочего места
- **THEN** действие «Открыть в рабочем месте» не показывается, а «Открыть в системе» остаётся доступным

### Requirement: Поиск книг

UI SHALL предоставлять поле поиска, фильтрующее список книг по названию и авторам в реальном времени. Поиск применяется к каталогу внешней библиотеки и к собственному каталогу.

#### Scenario: Фильтрация списка по запросу

- **WHEN** пользователь вводит текст в поле поиска
- **THEN** список книг обновляется, показывая только книги с совпадающим названием или автором

#### Scenario: Сброс поиска

- **WHEN** пользователь очищает поле поиска
- **THEN** UI возвращается к полному списку книг

### Requirement: Открытие книги во внешнем системном приложении

UI SHALL предоставлять действие «Открыть в системе», открывающее файл книги во
внешнем системном приложении по умолчанию для данного типа файла. Действие SHALL
быть доступно на странице книги. Клик по карточке книги SHALL открывать страницу
книги, а не файл во внешнем приложении.

#### Scenario: Открытие книги для чтения во внешнем редакторе

- **WHEN** пользователь выбирает книгу и нажимает «Открыть в системе»
- **THEN** файл книги открывается во внешнем системном приложении

#### Scenario: Клик по книге во внешней библиотеке

- **WHEN** пользователь нажимает на карточку книги в открытой внешней библиотеке
- **THEN** открывается страница книги, откуда доступно действие «Открыть в системе»

### Requirement: Ограничение импорта во внешней библиотеке

Во внешней библиотеке UI SHALL скрывать действие импорта новой книги.

#### Scenario: Скрытие импорта во внешней библиотеке

- **WHEN** открыта внешняя библиотека
- **THEN** UI не отображает действие добавления книги

### Requirement: Интерфейс активной библиотеки

Библиотечный UI SHALL быть встроенной поверхностью оболочки и отображать книги
активной библиотеки, обновляя их при открытии библиотеки. Каталог SHALL
запрашиваться у активного source-плагина opaque-операциями; оболочка не знает
устройства каталога. Имя активной библиотеки SHALL отображаться в верхней панели
оболочки, а не на странице книг. Библиотечный UI SHALL NOT содержать выбор
библиотеки и историю открытий — это принадлежит странице «Библиотеки» на уровне
оболочки. При отсутствии активной библиотеки UI SHALL показывать подсказку
открыть библиотеку на странице «Библиотеки».

#### Scenario: Открытие библиотеки снаружи

- **WHEN** библиотека открыта на странице «Библиотеки»
- **THEN** библиотечный UI перезагружает и показывает книги активной библиотеки

#### Scenario: Имя библиотеки в шапке

- **WHEN** библиотека открыта
- **THEN** её имя отображается в верхней панели оболочки, а страница книг показывает поиск и список книг

#### Scenario: Нет активной библиотеки

- **WHEN** активная библиотека не выбрана
- **THEN** UI показывает подсказку открыть библиотеку на странице «Библиотеки»

### Requirement: Прогресс построения индекса библиотеки

При открытии библиотеки, для которой требуется построение или актуализация
индекса, UI SHALL показывать определённый прогресс в процентах по мере обработки
книг. По завершении UI SHALL показывать каталог открытой библиотеки. Если индекс
актуален и обработка не требуется, UI SHALL NOT показывать прогресс, а библиотека
SHALL открываться сразу.

#### Scenario: Показ процентов во время индексации

- **WHEN** пользователь открывает библиотеку, требующую построения индекса
- **THEN** UI показывает прогресс-бар с долей обработанных книг в процентах

#### Scenario: Завершение индексации

- **WHEN** построение индекса завершено
- **THEN** UI скрывает прогресс и показывает каталог открытой библиотеки

#### Scenario: Актуальный индекс

- **WHEN** пользователь открывает библиотеку, индекс которой актуален
- **THEN** UI открывает библиотеку сразу и не показывает прогресс
