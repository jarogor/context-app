# book-import Specification

## Purpose

Импорт книг в формате EPUB в портируемую библиотеку с извлечением базовых метаданных и корректным сохранением файлов и данных без обращения к сети.

## Requirements

### Requirement: Импорт книги в формате EPUB

Приложение SHALL принимать на вход файл EPUB, копировать его содержимое в папку книг портируемой директории и извлекать из него базовые метаданные: название, список авторов и обложку.

#### Scenario: Успешный импорт книги с метаданными

- **WHEN** пользователь импортирует корректный файл EPUB с заполненными метаданными
- **THEN** создаётся запись книги с извлечёнными названием, авторами и обложкой, а файл копируется в папку книг библиотеки

#### Scenario: Импорт EPUB без метаданных

- **WHEN** импортируемый EPUB не содержит метаданных
- **THEN** книга добавляется с названием, производным от имени файла, и без обложки

#### Scenario: Ошибка чтения поврежённого файла

- **WHEN** импортируемый файл не является корректным EPUB
- **THEN** импорт отклоняется с сообщением об ошибке, и в базе данных не создаётся никаких новых записей

### Requirement: Уникальность файлов импортированных книг

Имена файлов книг в папке книг SHALL быть уникальными в пределах библиотеки, чтобы исключить перезапись или конфликты имён при импорте.

#### Scenario: Конфликт имени файла при импорте

- **WHEN** импортируемая книга получает имя файла, уже используемое другой книгой в библиотеке
- **THEN** новому файлу присваивается альтернативное уникальное имя без перезаписи существующего файла
