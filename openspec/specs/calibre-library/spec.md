# calibre-library Specification

## Purpose

Открытие существующей библиотеки Calibre как внешнего источника книг в режиме «только чтение», построение виртуального каталога при каждом запуске и предоставление книг для поиска и чтения.

## Requirements

### Requirement: Открытие библиотеки Calibre

Приложение SHALL распознавать директорию Calibre-библиотеки по типовой структуре Calibre (вложенные папки книг с файлом `metadata.opf`) и открывать её как внешнюю библиотеку; при этом файлы и папки Calibre-библиотеки SHALL оставаться без изменений.

#### Scenario: Открытие существующей библиотеки Calibre

- **WHEN** пользователь указывает путь к директории Calibre-библиотеки при открытии
- **THEN** приложение распознаёт её как Calibre-библиотеку, строит виртуальный каталог и позволяет работать с книгами без изменения файлов библиотеки

#### Scenario: Открытие пустой директории

- **WHEN** пользователь указывает путь к несуществующей или пустой директории
- **THEN** приложение создаёт собственную портируемую структуру библиотеки, а не формат Calibre

#### Scenario: Открытие своей портируемой библиотеки

- **WHEN** пользователь указывает путь к собственной портируемой библиотеке
- **THEN** приложение открывает её в собственном формате без признаков Calibre-режима

### Requirement: Read-only доступ к Calibre-библиотеке

Каталог Calibre-библиотеки SHALL быть доступен только для чтения: приложение SHALL не изменять и не удалять файлы Calibre-библиотеки и не создавать в ней новых файлов.

#### Scenario: Импорт книги в Calibre-библиотеку отклоняется

- **WHEN** пользователь пытается импортировать книгу в открытую Calibre-библиотеку
- **THEN** операция отклоняется с понятным сообщением об ошибке, и ни один файл Calibre-библиотеки не изменяется

### Requirement: Виртуальный каталог Calibre-библиотеки

Приложение SHALL строить виртуальный каталог книг из структуры Calibre-библиотеки при каждом запуске: папки книг, метаданные из `metadata.opf`, файлы содержимого и обложки. Каталог SHALL содержать для каждой книги название, авторов, файлы содержимого и путь к обложке.

#### Scenario: Книга с метаданными

- **WHEN** в Calibre-библиотеке есть книга с `metadata.opf`, файлом содержимого и обложкой
- **THEN** виртуальный каталог содержит запись книги с названием, авторами из `metadata.opf`, файлом содержимого и обложкой

#### Scenario: Книга без обложки

- **WHEN** в папке книги Calibre отсутствует файл обложки
- **THEN** книга присутствует в каталоге без обложки

#### Scenario: Повторное сканирование при запуске

- **WHEN** приложение запускается повторно с той же Calibre-библиотекой, в которой появились новые книги или папки
- **THEN** виртуальный каталог строится заново и отражает текущее содержимое Calibre-библиотеки

### Requirement: Поиск книг

Приложение SHALL предоставлять поиск по названию и авторам книг виртуального каталога Calibre-библиотеки.

#### Scenario: Поиск по названию

- **WHEN** пользователь вводит текст в поле поиска
- **THEN** возвращаются книги, название или авторы которых содержат введённый текст (без учёта регистра)

#### Scenario: Поиск без совпадений

- **WHEN** поисковый запрос не соответствует ни одной книге
- **THEN** возвращается пустой результат без ошибки

### Requirement: Открытие книги во внешнем приложении

Приложение SHALL позволять открыть файл книги виртуального каталога Calibre-библиотеки во внешнем системном приложении по умолчанию для данного типа файла.

#### Scenario: Открытие книги в системном приложении

- **WHEN** пользователь выбирает книгу и действие «Открыть в системе»
- **THEN** приложение запускает внешнее приложение по умолчанию для формата файла книги
