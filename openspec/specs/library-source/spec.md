# library-source Specification

## Purpose

Открытие произвольной директории с книгами как внешнего источника книг в режиме «только чтение», построение виртуального каталога и предоставление книг для поиска и чтения.

## Requirements

### Requirement: Открытие директории с книгами как библиотеки

Приложение SHALL распознавать директорию с книгами через поставляемый source-плагин `library` по типовой структуре «автор/книга» (вложенные папки книг с поддерживаемыми файлами книг) и открывать её как внешнюю библиотеку; при этом файлы и папки внешней библиотеки SHALL оставаться без изменений.

#### Scenario: Открытие существующей директории с книгами

- **WHEN** пользователь указывает путь к директории с книгами при открытии
- **THEN** приложение распознаёт её как внешнюю библиотеку, строит виртуальный каталог и позволяет работать с книгами без изменения файлов библиотеки

#### Scenario: Открытие пустой директории

- **WHEN** пользователь указывает путь к несуществующей или пустой директории
- **THEN** приложение создаёт собственную портируемую структуру библиотеки

#### Scenario: Открытие портируемой библиотеки

- **WHEN** пользователь указывает путь к портируемой библиотеке
- **THEN** приложение открывает её в собственном формате без признаков внешнего режима

### Requirement: Read-only доступ к внешней библиотеке

Каталог внешней библиотеки SHALL быть доступен только для чтения: приложение SHALL не изменять и не удалять файлы внешней библиотеки и не создавать в ней новых файлов.

#### Scenario: Импорт книги в внешнюю библиотеку отклоняется

- **WHEN** пользователь пытается импортировать книгу в открытую внешнюю библиотеку
- **THEN** операция отклоняется с понятным сообщением об ошибке, и ни один файл внешней библиотеки не изменяется

### Requirement: Виртуальный каталог внешней библиотеки

Приложение SHALL строить виртуальный каталог книг из структуры внешней библиотеки при первом открытии или при необходимости полной перестройки: папок книг, метаданных из имён файлов и папок, файлов содержимого и обложек. При последующих открытиях приложение SHALL использовать согласованный индекс из `.booklib`, проверять изменения источника и SHALL актуализировать только затронутые записи, если полная перестройка не требуется. Каталог SHALL содержать для каждой книги название, авторов, файлы содержимого и путь к обложке.

#### Scenario: Книга с метаданными

- **WHEN** в директории есть книга с поддерживаемым файлом содержимого и обложкой
- **THEN** виртуальный каталог содержит запись книги с названием, авторами, файлом содержимого и обложкой

#### Scenario: Книга без обложки

- **WHEN** в папке книги отсутствует файл обложки
- **THEN** книга присутствует в каталоге без обложки

#### Scenario: Повторное открытие без изменений

- **WHEN** приложение повторно открывает библиотеку, для которой существует актуальный локальный индекс и не обнаружены изменения
- **THEN** каталог восстанавливается из индекса без полного сканирования всех книг

#### Scenario: Новая книга после предыдущего открытия

- **WHEN** после предыдущего открытия в библиотеке появилась новая книга
- **THEN** каталог дополняется новой книгой после инкрементальной синхронизации или проверки при открытии

#### Scenario: Повторное сканирование при запуске

- **WHEN** приложение запускается повторно с той же библиотекой, в которой появились новые книги или папки, а индекс отсутствует, повреждён или признан несовместимым
- **THEN** виртуальный каталог строится заново и отражает текущее содержимое библиотеки

### Requirement: Поиск книг

Приложение SHALL предоставлять поиск по названию и авторам книг виртуального каталога внешней библиотеки.

#### Scenario: Поиск по названию

- **WHEN** пользователь вводит текст в поле поиска
- **THEN** возвращаются книги, название или авторы которых содержат введённый текст (без учёта регистра)

#### Scenario: Поиск без совпадений

- **WHEN** поисковый запрос не соответствует ни одной книге
- **THEN** возвращается пустой результат без ошибки

### Requirement: Открытие книги во внешнем приложении

Приложение SHALL позволять открыть файл книги виртуального каталога внешней библиотеки во внешнем системном приложении по умолчанию для данного типа файла.

#### Scenario: Открытие книги в системном приложении

- **WHEN** пользователь выбирает книгу и действие «Открыть в системе»
- **THEN** приложение запускает внешнее приложение по умолчанию для формата файла книги
