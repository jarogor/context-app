# Контекст

**Контекст** («Context») — приложение для исследователя книг: нелинейное чтение,
заметки и рабочие места в одном инструменте. Несколько библиотек одновременно
(своя папка, Calibre, сторонние источники), всё локально, без облака и аккаунтов.

## Статус

Приложение **в разработке**: пишется с нуля, данные разработки можно удалять.
Служебные документы версионируются схемами: новая версия вводится вместе с шагом
приведения из прежней, производные данные (например, индекс библиотеки)
пересобираются.

## Устройство

Ядро — Rust (Tauri 2), интерфейс — Svelte 5. Доменная логика — в плагинах: WASM
в песочнице Extism без прямого доступа к файловой системе и сети; операции даёт
ядро. Источники книг распознают и индексируют библиотеки, форматы чтения рисуют
содержимое книги, каркасные плагины заведуют настройками и стором.

Интерфейс строится только из общей дизайн-системы `@context/ui`; автономных
frontend-плагинов нет — интерфейс областей принадлежит приложению.

Подробнее: `CONCEPT.md` — устройство и инварианты, `AGENTS.md` — правила
разработки.

## Стек

- **Ядро:** Rust, Tauri 2, SQLite (rusqlite)
- **Фронтенд:** Svelte 5, Vite, Tailwind v4
- **Плагины:** Extism (WASM, Rust PDK)
- **Сборка:** npm workspaces + Cargo workspaces

## Структура

```
src/                 оболочка: разделы, области, общие модули
packages/            @context/ui (дизайн-система), ui-schema, i18n, testing
src-wasm-plugins/    исходники WASM-плагинов
src-wasm-sdk/        SDK каркаса: протоколы, индексы, парсеры, миграции
src-tauri/           Rust-ядро и конфигурация Tauri
schemas/             схемы служебных JSON-документов и примеры
scripts/             сборка WASM-плагинов
```

## Разработка

Нужны Rust с целью `wasm32-unknown-unknown`, Node.js и системные зависимости
Tauri для Linux (GTK, webkit2gtk).

```bash
npm install
make dev          # desktop-запуск (Tauri), плагины собираются автоматически
make dev-test     # Vite с мок-мостом Tauri — интерфейс без десктопа
make help         # все задачи
```

Проверки перед завершением задачи — одной командой:

```bash
make verify
```

`make verify` собирает плагины, проверяет артефакты, прогоняет тесты Rust и
фронтенда, `clippy`/`fmt`, `svelte-check`, браузерные тесты и полную сборку.
Отдельные шаги: `make plugins`, `make test`, `make rust-check`, `make check`,
`make e2e`, `make build`.
