# Контекст

**Контекст** («Context») — приложение для исследователя книг: чтение текста и ведение заметок в одном рабочем месте.
Приложение поддерживает несколько библиотек одновременно (собственная, Calibre, другие источники) и быстрое переключение между ними.
Всё работает локально: без облака и аккаунтов, библиотека и заметки переносимы.

## Как устроено

Ядро написано на Rust (Tauri 2), интерфейс — на Svelte. Доменная логика вынесена
в плагины: ядро не знает о конкретных форматах книг и источниках, а только
маршрутизирует непрозрачные операции. Source-плагины распознают и сканируют
библиотеки, базовые заведуют каркасом приложения (уведомления, настройки, стор),
extension-плагины добавляют остальное. Плагины — это WASM-модули (Extism) в
песочнице: без прямого доступа к файловой системе и сети, доступные операции
предоставляет ядро.

Оболочка строит интерфейс только из общей дизайн-системы `@context/ui`;
автономных frontend-плагинов нет — интерфейс встроенных областей
принадлежит приложению, а сторонние плагины описывают свой интерфейс
декларативно (`ui-schema`), и оболочка рендерит его той же дизайн-системой.
Код организован по vertical slice: каждая Tauri-команда проходит срез
«command → сервис → репозиторий» без лишних абстракций.

## Идентификаторы

- Пакеты Rust и npm: `context_app` и `context-app`.
- Идентификатор приложения Tauri: `ru.jarogor.context_app`.
- Название для пользователя: **Контекст** (**Context**).

## Стек

- **Ядро:** Rust, Tauri 2, SQLite (rusqlite)
- **Фронтенд:** Svelte 5, Vite, Tailwind v4
- **Плагины:** Extism (WASM, Rust PDK)
- **Сборка:** npm workspaces + Cargo workspace

## Структура

```
src/                 фронтенд-оболочка (App.svelte, встроенные области)
packages/ui          дизайн-система @context/ui
src-wasm-plugins/    исходники WASM-плагинов (Cargo workspace)
src-tauri/           Rust-ядро и конфигурация Tauri
scripts/             сборка WASM-плагинов
openspec/            спеки и изменения (spec-driven)
```

## Разработка

Требования: Rust с целью `wasm32-unknown-unknown`, Node.js, системные зависимости
Tauri для Linux (GTK, webkit2gtk).

```bash
npm install
make dev            # desktop-запуск (Tauri); плагины собираются автоматически
make dev-test       # Vite с мок-мостом Tauri (интерфейс без десктопа)
```

Все задачи собраны в `Makefile` (`make help`). Артефакты плагинов генерируются
из `src-wasm-plugins/` и в git не хранятся; команды собирают их сами, поэтому
отдельно помнить про пересборку не нужно.

Проверки перед завершением задачи — одной командой:

```bash
make verify
```

Отдельные шаги: `make plugins`, `make check-artifacts`, `make test`,
`make rust-check`, `make check`, `make e2e`, `make build`, `make validate`.
`make rust-check` линтует и ядро, и WASM-плагины (`src-wasm-plugins` под
`wasm32-unknown-unknown`), а `make test` прогоняет тесты обоих крейтов.
