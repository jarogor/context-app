# LIBRARY-PROPERTIES-PLAN — свойства книги, сортировка и фильтрация библиотеки

Рабочий план: модель свойств книги, порядок в индексации, сортировка и
фильтрация на странице библиотеки. Это **журнал работ**: статус каждой задачи
отмечается здесь же по мере выполнения.

Статусы: `[ ]` — не начато · `[x]` — сделано · `[~]` — отложено (с причиной).

Источники истины: `CONCEPT.md` (устройство каркаса, приложения и плагинов),
`ROADMAP.md` (направление и приоритеты), этот файл (конкретный объём работ).

## 2. Целевая модель свойств книги

Слой источника (индекс, производные данные) → пользовательский слой
(приложение) → (позже) плагины-обогатители.

| Поле | Тип | Обязательность | Откуда | Владелец | Сортировка | Фильтр |
| --- | --- | --- | --- | --- | --- | --- |
| Название | string | есть всегда (фолбэк — имя файла) | файл → источник → правка | источник + правка | да | поиск |
| Автор(ы) | string[] | поле есть всегда, значение может быть пустым | файл/OPF → источник → правка | источник + правка | да | фасет |
| Формат | enum | есть всегда (из расширения) | структурный факт | источник | да | фасет |
| Серия + номер | (string, int) | нет | OPF/EPUB/Calibre | источник | да | фасет |
| Теги источника | string[] | нет | OPF/Calibre | источник | — | фасет |
| Дата выхода | строка ISO-даты | нет | EPUB `dc:date`, FB2 `<date>`, OPF `dc:date` | источник | да | год |
| Язык | строка (BCP-47) | нет | EPUB `dc:language`, FB2 `<lang>`, OPF, PDF `/Lang` | источник | — | фасет |
| Издатель, идентификатор (ISBN), описание | string | нет | OPF/EPUB/FB2 | источник | — | — |
| Размер | int (байт) | есть всегда (производное) | `fs_list_dir` | источник | да | — |
| Дата добавления | timestamp | нет (производное) | первый `sync` (новое поле индекса) | источник | да | — |
| Путь к файлу | string | есть всегда (производное) | корень + относительный путь | оболочка | — | — |
| Наличие обложки | bool | есть всегда | индекс/кэш | источник | — | да |
| Пользовательские теги | string[] | нет | пользователь | **приложение** | — | фасет |
| Правки (название, авторы, язык, дата) | overlay | нет | пользователь | **приложение** | да (по итоговому) | фасет |

Два разных понятия, которые нельзя смешивать:

- **свойства книги** (эта таблица) — список и страница книги;
- **свойства открытого файла** (содержание, закладки, превью, пометки) — уже
  есть отдельная панель рабочего места (`reader-cache`, плагины формата).

## 3. Принятые решения (по умолчанию — до ревью)

1. **Идентичность книги** — абсолютный путь (как у заметок и кэша обложек).
   Стабильный ключ (хеш/идентификатор) — отдельная задача вне этого объёма.
2. **«Автор обязательно»** — поле присутствует всегда, значение может быть
   пустым и показывается как «Не указан»; пользователь заполняет правкой.
3. **Дата для PDF/DjVu** — не заполняется: `/CreationDate` — дата файла, а не
   издания; выдавать её за дату выхода нельзя. У PDF берётся только `/Lang`.
4. **Размер при нескольких файлах** — сумма файлов содержимого.
5. **Пользовательские теги** — по книге (ключ — абсолютный путь), не привязаны
   к библиотеке.
6. **Сортировка по умолчанию** — по названию; «по порядку» заменяется на «дата
   добавления» (новые сверху).
7. **Мультивыбор фильтров** — чекбоксы в панели фильтров (`Dialog` +
   `Checkbox`), без нового компонента дизайн-системы.
8. **Этап 7 (плагины-обогатители)** — вне этой итерации: значения добавлять
   пока нечем (нет сетевого источника), а «мёртвый» контракт хуже его
   отсутствия. Возврат к этапу — при появлении сценария обогащения.
9. **Спека** — `openspec/` в репозитории нет; источник истины — этот файл,
   `CONCEPT.md` и `ROADMAP.md`.
10. **Версии — только 1.** Приложение не в продакшне и пишется с нуля: схема
    каталога и протокол источника сразу версия 1, цепочек версий и совместимости
    между ними нет. Новые версии вводятся, когда появится необходимость, а не
    заранее; проверки «каталог новее приложения» в этой итерации нет.

## 5. Итерация 2: правки по замечаниям к интерфейсу — `[x]`

Замечания к первой итерации: пользоваться библиотекой неудобно — выпадающие
списки разбросаны, фильтры сплошной портянкой, пустые свойства занимают место,
названия полей непонятны, теги задвоены.

- [x] **2.1** Выпадающие списки из полосы управления убраны. Сортировка и
      фильтры живут в **боковой панели** (`SidePanel`), кнопка «Фильтры» в
      полосе открывает и закрывает её; на узком окне панель перекрывает
      содержимое и закрывается кнопкой.
- [x] **2.2** Разделы панели сворачиваются (`Disclosure` из `@context/ui`):
      «Сортировка» (поля и направление), «Обложка», фасеты автор/формат/язык/
      серия/теги. Длинный список авторов больше не заслоняет остальные фильтры.
- [x] **2.3** Фильтр «Все книги / С обложкой / Без обложки» переехал в панель и
      входит в счётчик активных фильтров; отдельного списка в полосе нет.
- [x] **2.4** Подписи дат пояснены: «Дата выхода книги» и «Дата добавления
      файла» — и в свойствах книги, и в вариантах сортировки.
- [x] **2.5** Страница книги показывает только заполненные свойства; пустые
      строки и пустые разделы не рисуются (сообщения «Не указано» нет).
- [x] **2.6** Разделы свойств книги сворачиваются и по умолчанию закрыты.
- [x] **2.7** Правка — по группам: у «Основное», «Издание» и «Теги» своё
      действие в заголовке раздела и свой диалог. «Как в файле» заменено на
      «Взять из файла»; пояснения про индекс и пересборку удалены.
- [x] **2.8** Теги у книги одни: теги файла и теги пользователя — один список.
      Правка тегов заменяет теги файла целиком, «Взять из файла» возвращает их.
      Отдельного фасета и отдельной строки «Мои теги» больше нет.
- [x] **2.9** В списке библиотеки строки чередуются подложкой
      (`--surface-inset`), чтобы длинный список не сливался.
- [x] **2.10** Подсказка при наведении на книгу — название книги, а не «Страница
      книги».
- [x] **2.11** Обложки: в каталог добавлен признак «есть обложка» (из индекса),
      а сами обложки запрашиваются пакетно **только для видимых книг страницы**
      и запоминаются по идентификатору. Раньше base64 всех обложек тянулся на
      весь каталог — отсюда задержка в несколько секунд на большой библиотеке.
      Файловый кэш ядра теперь не запоминает неудачное извлечение как «обложки
      нет»: иначе книга навсегда оставалась бы без обложки.

- [x] **2.12** Панель фильтров — внутри страницы: полоса управления сверху и
      постраничность снизу идут во всю ширину над и под панелью, а не только
      над списком. На узком окне панель перекрывает только область списка, не
      закрывая верхнюю полосу.

Проверено: `cargo test` плагинов и SDK, `clippy`/`fmt` (host и `wasm32`),
`svelte-check`, модульные тесты (651) и `@context/ui` (149), сборка плагинов и
артефакты, браузерные тесты библиотеки, страницы книги, мобильной и адаптивной
вёрстки; снимок страницы книги обновлён (страница изменилась намеренно).
