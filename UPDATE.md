# Обновления

Обновления разделены по границе каркаса и приложения:

- **Ядро** — исполняемый файл и каркасные плагины (`base-plugins`: настройки,
  стор). Обновляется **одним пакетом из одного источника**: они связаны
  контрактом и по отдельности не заменяются.
- **Прикладные плагины** — источники книг, заметки, форматы чтения, расширения.
  Обновляются **по отдельности** через стор из любых подключённых мест.
  Пользовательская копия плагина с тем же идентификатором перекрывает
  поставляемую.

## Источник

Источник добавляется в настройках в разделе «Система» (обновления приложения и
плагинов). По умолчанию:
в разработке — `dev_data/updates` для ядра и `dev_data/plugin-updates` для
плагинов, в выпуске — `https://updates.jarogor.ru/context` и
`.../plugins`. Ядро переопределяется при сборке `CONTEXT_UPDATE_URL`, оба
источника — переменными `CONTEXT_UPDATE_SOURCE` и `CONTEXT_PLUGIN_SOURCE`
в формате `file:/путь` или `network:https://адрес`.

Источник — каталог или базовый адрес с двумя независимыми индексами:

- `update-index.json` — ядро;
- `store-index.json` — прикладные плагины.

Источник может содержать оба, один или ни одного: пустой источник не ошибка.

Сетевой источник — только HTTPS (HTTP допустим для `localhost`/`127.0.0.1`).
Для сетевых артефактов SHA-256 обязательна, для файловых проверяется, если
указана.

## Индекс ядра — `update-index.json`

```json
{
  "contract_version": 1,
  "core": {
    "version": "0.2.0",
    "notes": "Что изменилось",
    "platforms": {
      "linux-x86_64": {
        "mode": "appimage",
        "location": "Context_0.2.0_amd64.AppImage",
        "sha256": "<hex>"
      },
      "windows-x86_64": {
        "mode": "installer",
        "location": "Context_0.2.0_x64-setup.exe",
        "sha256": "<hex>"
      },
      "darwin-aarch64": {
        "mode": "portable",
        "location": "Context_0.2.0_aarch64.zip",
        "sha256": "<hex>"
      }
    }
  }
}
```

Ключ платформы — `ОС-архитектура` (`linux`/`windows`/`darwin`,
`x86_64`/`aarch64`/`i686`/`armv7`).

## Способы установки ядра

- `portable` — zip, содержимое которого накладывается на каталог установки
  (на macOS — корень `.app`). Пакет содержит исполняемый файл, `base-plugins` и
  остальные ресурсы; старое содержимое каталога заменяется.
- `appimage` — готовый AppImage, заменяет текущий файл `$APPIMAGE`.
- `installer` — штатный установщик платформы, запускаемый после выхода
  приложения.

После подготовки приложение завершается, помощник ждёт выхода, применяет пакет и
запускает новую версию. Журнал применения —
`app-state/updates/<версия>-<режим>/apply.log`.

## Индекс плагинов — `store-index.json`

```json
{
  "packages": [
    {
      "id": "d3b8f2a1-6c4e-4f7a-9b2d-1e5c8a7f0b3d",
      "name": "format-pdf",
      "version": "0.2.0",
      "kind": "format",
      "description": "Чтение PDF",
      "location": "format-pdf-0.2.0.zip",
      "sha256": "<hex>"
    }
  ]
}
```

Стор сравнивает версию пакета с установленной или поставляемой и предлагает
обновление. Установка заменяет каталог плагина целиком, не затрагивая его
служебное состояние (оно хранится отдельно). Для сетевого стора `sha256`
обязательна. Подпись пакетов издателя — следующий шаг перед публичным сетевым
стором.
